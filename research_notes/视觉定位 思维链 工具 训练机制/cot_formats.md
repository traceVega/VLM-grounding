## Key Question 1 — What exactly is the CoT format (fields/steps before the box) and the exact reward terms, per method?

### Takeaway
There are four distinct families of "reasoning before the box": (a) **candidate-indexed per-attribute verification** (Rex-Thinker: Grounding DINO boxes injected as numbered hints, Planning → per-candidate Action → Summarization, answer copies a hint box or an empty list), (b) **free-form `<think>` then a JSON box** (VLM-R1, UniVG-R1, Ref-R1, multi-image grounding RL, RSGround-R1, EGM), (c) **evidence boxes/points embedded in the trace and rewarded** (TreeVGR dual-IoU, ViGoRL coordinates, GRIT, Point-RFT, Ground-R1, VGR replay, "Thinking with Visual Grounding"), and (d) **rigid multi-field templates with a self-critique slot** (SATORI caption→bbox→answer; the 2026 part-level grounding template `<locate>/<target>/<object_hint>/<first_answer>/<criticism>/<answer>`). Rewards are almost always `format (0/1) + IoU-type accuracy`; the exceptions that reward the *trace itself* are TreeVGR (recall+precision IoU over trace boxes), GRIT (box-count), ViGoRL (coordinate validity, diversity bonus), RC-GRPO stage II (rationale names the false phrase), Faithful GRPO (consistency/grounding constraints) and the part-level template (improvement / adjustment-consistency penalties).

### Cited Findings

**Rex-Thinker (Qwen2.5-VL-7B; ICLR 2026 poster)**
- Prompt template: system prompt + `Hint: Object and its coordinates in this image: Box Hint` + `User: Locate Referring`; output must be `<think> reasoning </think> <answer> answer </answer>`; the Box Hint is a JSON like `{"person": [[101, 10, 140, 200],[122, 15, 162, 205], ...]}` produced by Grounding DINO for the head-noun category, and candidates are referred to in the trace as "Person 1", "Person 2" in the order of the hints `[PDF, Table 1 and §4]` — [arXiv 2506.04034](https://arxiv.org/abs/2506.04034)
- Three stages: Planning (decompose the expression into sub-goals), Action (evaluate each candidate against each sub-goal), Summarization (aggregate and emit the final boxes; empty set when nothing matches) — [arXiv 2506.04034](https://arxiv.org/abs/2506.04034)
- Accuracy reward is an F1 where "a match [is defined] only when a predicted box exactly overlaps with a ground-truth box (i.e., IoU = 1), which encourages the model to select final outputs directly from the box hints"; format reward r_fmt = 1 iff `<think>`/`<answer>` structure is respected `[PDF §4.2.3]` — [arXiv 2506.04034](https://arxiv.org/abs/2506.04034)
- Combined reward r = 0.9·r_F1 + 0.1·r_fmt `[HTML summary]`; the released reward code scores empty-vs-empty as 1.0 and any box on a rejection item as 0 `[project note, citing repo scripts/reward_func.py]` — [GitHub IDEA-Research/Rex-Thinker](https://github.com/IDEA-Research/Rex-Thinker)
- HumanRef-CoT: 90,824 traces generated by GPT-4o with set-of-mark visualization (GT targets green, others red) and per-subset in-context examples; only examples where GPT-4o's final prediction matched GT were kept `[HTML summary]` — [arXiv 2506.04034](https://arxiv.org/abs/2506.04034)
- GRPO stage: LLM-only, lr 1e-6, 8 rollouts, batch 8, grad-accum 2, KL β = 0.04, temperature 1.0, 2048 output tokens `[PDF §5.1]`; SFT stage lr 2e-5, 2 epochs, batch 4 × accum 4, vision encoder frozen, 8×A100 ≈ 10.1 h; GRPO ≈ 112 h on 8×A100, stopped at reward plateau (~0.25 epoch) `[HTML summary; not re-read in PDF]` — [arXiv 2506.04034](https://arxiv.org/abs/2506.04034)
- Inference cost: Rex-Thinker-GRPO 6.68 s/image vs Rex-Thinker-Plain 1.13 s/image on one A100 with vLLM (~560 completion tokens typical) `[HTML summary]` — [arXiv 2506.04034](https://arxiv.org/abs/2506.04034)
- OpenReview: ICLR 2026 poster, three official reviews rated 4 / 6 / 6 (forum `btWHQoSZZ1`); review text was not retrievable (browser challenge) — [OpenReview forum](https://openreview.net/forum?id=btWHQoSZZ1)

**ChatRex / VLM-FO1 / CRS — index-retrieval formats (precursors of Rex-Thinker's candidate hints)**
- ChatRex feeds Universal Proposal Network boxes into the LLM "allowing it to output the corresponding box indices ... turning the regression task into a retrieval-based task"; motivation: Qwen2-VL reaches only 43.9 recall on COCO — [arXiv 2411.18363](https://arxiv.org/abs/2411.18363)
- VLM-FO1 (Qwen2.5-VL-3B base; SFT only, two stages) encodes proposal boxes as region tokens `<region0>…<regionN-1>` and grounds phrases as `<ground>people</ground><object><region2><region10></object>`; 20% of training prompts ask for objects not present (rejection samples); results: COCO mAP 44.4 vs Qwen2.5-VL-7B 17.7; OVDEval 43.7 mAP (Grounding DINO 25.3); RefCOCO val 91.12 / RefCOCO+ val 86.4 / RefCOCOg val 88.9; HumanRef F1 82.6 vs ChatRex 55.6; OpenCompass avg 64.6 vs 64.5 for the base `[HTML summary]` — [arXiv 2509.25916](https://arxiv.org/abs/2509.25916)
- CRS (TPAMI 2025): Grounding DINO proposes top-k boxes, the MLLM answers a multiple-choice prompt "by outputting a single token (e.g., 'A')" with an explicit "None" option; instruction-tuned with 2k–12k RefCOCO items plus 10k positive + 2.5k negative FineCops-Ref items for the None option; no CoT `[HTML summary]` — [arXiv 2502.20104](https://arxiv.org/abs/2502.20104)

**UniVG-R1 (Qwen2-VL-7B)**
- Format `<think>thinking process here</think><answer>(x1, y1), (x2, y2)</answer>`; cold-start traces: MGrounding-630k samples, Qwen-VL-MAX writes 3 chains, judge picks the best → 76k + 14k RefCOCO/+/g = 90k CoT-SFT; 10% manually checked, 99.87% accepted `[HTML summary]` — [arXiv 2505.14231](https://arxiv.org/abs/2505.14231)
- GRPO on 10k (7k MGrounding + 3k RefCOCO), lr 1e-6, batch 16, 8 rollouts, max 256 completion tokens; reward r = IoU(B_pred, B_GT) + format ∈ [0, 2]; difficulty-aware weight φ = exp(1 − mIoU_group) multiplies the policy-gradient term `[HTML summary]` — [arXiv 2505.14231](https://arxiv.org/abs/2505.14231)

**VLM-R1 (Qwen2.5-VL-3B; RL only)**
- Prompt: "Please provide the bounding box coordinates of the region this sentence describes: {query}. Output the thinking process in <think></think> and final answer in <answer>...</answer> tags"; answer is JSON `[x1, y1, x2, y2]`; REC reward = IoU(b*, f_rec(o)) + format(0/1); GRPO N = 8, temperature 0.9, β = 0.04, lr 1e-6, 2 epochs; OVD reward `odLength` = min(1, L_gt/L_pred) · mAP to stop the "predict every category" reward hack `[HTML summary]` — [arXiv 2504.07615](https://arxiv.org/abs/2504.07615)

**Vision-R1 (2503.18013; Qwen2.5-VL-7B and Griffon-G-7B; RL only, no CoT)**
- "object localization tasks typically do not involve intermediate steps but directly output the final result"; rewards: dual-format (binary), recall = #valid / #GT with valid = IoU ≥ ξ0, precision = Σ 1[IoU_m ≥ ξ0]·IoU_m / M, summed; progressive rule refinement f(x) = 1 if x ≥ ξ2, 0 if x < ξ1, x otherwise, with (ξ0, ξ1, ξ2) = (0.5, 0.5, 0.75) early and (0.75, 0.75, 0.9) late; 49K samples (30K detection + 9K grounding + 10K REC), lr 1e-6, β = 0.2, 1 epoch `[HTML summary]` — [arXiv 2503.18013](https://arxiv.org/abs/2503.18013)

**Rex-Omni (Qwen2.5-VL-3B; CVPR 2026; no CoT)**
- Coordinates are 1,000 special tokens (0–999); a box is two points; output `<|object_ref_start|>PHRASE<|object_ref_end|><|box_start|>COORDS<|box_end|>`; "If a particular phrase refers to an object that is not present in the image, the corresponding COORDS field is replaced with None" `[PDF]` — [arXiv 2510.12798](https://arxiv.org/abs/2510.12798)
- SFT on 22M samples (~8 days on 8 nodes × 8 A100), then GRPO on 66K samples (8×A100 ≈ 24 h, 8 rollouts, batch 64, β = 0.01); rewards: box-IoU F1 (2PR/(P+R+ε), category must match), point-in-mask (SAM masks), point-in-box for GUI `[HTML summary]` — [arXiv 2510.12798](https://arxiv.org/abs/2510.12798)
- Token cost: 7.6 output tokens per box on COCO and 5.1 on Dense200 vs SEED1.5-VL 148.8 / 74.5 `[PDF Table 17]` — [arXiv 2510.12798](https://arxiv.org/abs/2510.12798)

**Perception-R1 (Qwen2-VL-2B for grounding/OCR/counting, Qwen2.5-VL-3B for detection; RL only, thinking removed)**
- Output is the bare `[x1,y1,x2,y2]`; format reward S_format = +1 correct / −1 incorrect; answer reward Φ per task (IoU for grounding; Hungarian bipartite matching for counting/detection; edit distance for OCR); S_total = S_format + S_answer; GRPO 8 rollouts, batch 11, lr 1e-6, KL 0.04, 2048 tokens; 5k RefCOCO/+/g samples `[HTML summary; Table 5 read in PDF]` — [arXiv 2504.07954](https://arxiv.org/abs/2504.07954)

**TreeVGR / TreeBench (Qwen2.5-VL-7B; ICLR 2026)**
- Format: `<think>` … boxes `[x1, y1, x2, y2]` … `</think><answer>…</answer>`; reward R = R_acc + R_format + R_IoU with R_IoU = ½(R_IoU^recall + R_IoU^precision), recall = mean over GT evidence boxes of max IoU with a trace box, precision = mean over trace boxes of max IoU with a GT box; cold-start SFT then GRPO for 5 epochs on TreeVGR-RL-37K with EasyR1 (DAPO tried, found unstable) `[PDF App. E]` — [arXiv 2507.07999](https://arxiv.org/abs/2507.07999)

**ViGoRL (Qwen2.5-VL-3B/7B)**
- Each step n_t = ⟨s_t, (x_t, y_t)⟩: a sentence anchored to a pixel coordinate; cold-start via MCTS with a frozen Qwen2.5-VL-72B (~30k traces from 1,500 prompts, including backtracking chains); single-turn reward R = λ_fmt·r_fmt + λ_task·r_task where r_fmt = 1 only if tags are valid AND every coordinate lies inside the image; multi-turn variant adds a grammar automaton reward and a diversity bonus +0.2 per new coordinate ≥ 10 px from previous ones (max 4) `[HTML summary]` — [arXiv 2505.23678](https://arxiv.org/abs/2505.23678)

**GRIT (Qwen2.5-VL-3B, InternVL3-2B; RL only, 20 training examples)**
- `<think>` text interleaved with box quadruplets, then `<rethink>`, then `<answer>`; r = r_format + r_count + r_ans with r_format = 0.5 (think pair) + 0.5 (rethink pair) + 0.5 (≥ 1 syntactically valid box), r_count = 0.5 if #boxes = GT object count (counting tasks only), r_ans = GPT-4o binary + 0.1·BLEU-1; GRPO-GR 200 steps, batch 128, 4 completions, lr 2e-6, 8×A100 ≈ 12 h `[HTML summary]` — [arXiv 2505.15879](https://arxiv.org/abs/2505.15879)

**Ground-R1 (Qwen2.5-VL-7B; RL only, "we do not employ curated SFT dataset for cold-start")**
- Template `<think>…</think> <box>[x1,y1,x2,y2]</box> <think>…</think> <answer>…</answer>`; the crop of the evidence box is fed back for the answering phase; SRPO = GRPO with intra-bin advantages (K = 3 box-scale bins) plus an inter-bin term (1 for the bin with highest mean reward); rewards are format + answer (exact match / ROUGE) only — no IoU term; 8×H100, 1,000 steps, batch 8, lr 1e-6, ≈ 12 h, G1 = 4 grounding rollouts × G2 = 2 answers `[HTML summary]` — [arXiv 2505.20272](https://arxiv.org/abs/2505.20272)

**Point-RFT (Qwen2.5-VL-7B)**
- `<think><points x0="…" y0="…" …>description</points> reasoning … </think><answer>…</answer>`, raw-pixel coordinates; Point-SFT data 71k (GPT-4o rationales with `<point>` placeholders, Molmo-7B fills coordinates, cross-validated counts, 95% judged high quality); SFT 500 steps batch 512 lr 5e-5, then GRPO 100 steps batch 56, β = 0; reward = format (regex) + accuracy (exact, ±5% numeric) `[HTML summary]` — [arXiv 2505.19702](https://arxiv.org/abs/2505.19702)

**SATORI-R1 (Qwen2.5-VL-3B/7B; RL only)**
- Fixed three-slot template `<caption>…</caption><bbox>[[…],[…]]</bbox><answer>…</answer>`; rewards: caption (BLEU-4 + ROUGE-L)/2, bbox union-IoU, answer 0/1, format 0/1 `[HTML summary]` — [arXiv 2505.19094](https://arxiv.org/abs/2505.19094)

**Seg-Zero / VisionReasoner / Visual-RFT / One-RL (free `<think>` + JSON, IoU-type rewards, RL only)**
- Seg-Zero: `<think>…</think><answer>{bbox, points_1, points_2}</answer>`; rewards: think-format, seg-format soft/strict, bbox IoU (1 if > 0.5), bbox L1 (1 if < 10 px), point L1 (1 if < 100 px); 9k RefCOCOg samples, batch 16, 8 samples, lr 1e-6 `[HTML summary]` — [arXiv 2503.06520](https://arxiv.org/abs/2503.06520)
- VisionReasoner: answer `[{"bbox_2d": [...], "point_2d": [...]}, …]`; six rewards (think format 1.0, answer format 1.0, non-repeat 1.0, bbox IoU, bbox L1 < 10 px, point L1 < 30 px, each +1/max{N,K} per matched prediction with Hungarian matching); 7k samples, 8 GPUs, 6 h `[HTML summary]` — [arXiv 2505.12081](https://arxiv.org/abs/2505.12081)
- Visual-RFT: `<think>…</think><answer>[{'Position': [x1,y1,x2,y2], 'Confidence': c}]</answer>`; R = mean IoU + confidence reward (c for matched, 1 − c for unmatched) + format `[HTML summary]` — [arXiv 2503.01785](https://arxiv.org/abs/2503.01785)
- One RL to See Them All (Qwen2.5-VL-7B/32B): detection format `[{'bbox_2d': [...], 'label': ...}]` in `<answer>`; Dynamic IoU reward: accuracy = IoU if IoU ≥ ε else 0, with ε stepping 0.85 → 0.95 → 0.99 at 10% / 15% / rest of training; format reward 0.25 × count of the 4 tags `[HTML summary]` — [arXiv 2505.18129](https://arxiv.org/abs/2505.18129)

**RC-GRPO (Qwen2.5-VL-7B, Qwen3-VL-4B, MiniCPM-V-4.6; LoRA)**
- No think tags; refusal is the literal string "There are none"; stage-II prompt adds "Also briefly explain the reason why it does not exist" `[HTML summary]`; forced-rejection rollout: "if no completion contains 'None,' we apply constrained beam search to force the output 'There are none'"; contrastive reward R_pos = 1 (IoU ≥ 0.5) / 0 (IoU < 0.5) / −1 (model says None); R_neg = 1 if None else 0; negative advantages scaled by α ∈ (0, 1] `[PDF Eq. 1–3]` — [arXiv 2608.04698](https://arxiv.org/abs/2608.04698)
- Stage II rationale reward r_reason = 0.5·1[trace names the incorrect phrase] + 0.3·1[names the original phrase], added to a base refusal reward 0.2 on None outputs `[HTML summary]` — [arXiv 2608.04698](https://arxiv.org/abs/2608.04698)
- "We use LoRA for all training stages, each trained for one epoch (500 steps): SFT on 2×A800 GPUs with batch size 1 and gradient accumulation 2, GRPO with VLM-R1 using 8 generations and batch size 8" `[PDF]` — [arXiv 2608.04698](https://arxiv.org/abs/2608.04698)

**Ref-R1 / RefBench-PRO (Qwen2.5-VL-7B)**
- `<think>…</think><answer>[x1, y1, x2, y2]</answer>`; 180K traces from RefObjects-200k written by Qwen2.5-VL-72B (best of several); RL 80k samples, 5,000 steps, DyIoU-GRPO reward = format + dynamic-IoU with threshold τ(t, s) = max(α + (β − α)·t/T − d_max·(1 − s), α), α = 0.5 → β = 0.8, plus a "group quality" bonus k/n for correct answers in hard groups; full fine-tuning, lr 5e-6 (SFT) / 1e-6 (RL), batch 16, 8×A800 `[HTML summary; τ schedule also in project note]` — [arXiv 2512.06276](https://arxiv.org/abs/2512.06276)

**Multi-image grounding RL (Qwen2.5-VL-7B; 2507.00748)**
- Prompt "…First output the thinking process in <think> </think> tags and then output the final answer in <answer> </answer> tags. Output the bounding box coordinates in JSON format."; cold-start 56k traces (54k MGrounding-630k + 1k RefCOCO + 1k ODINW/V3Det) from Qwen2.5-VL-72B, keeping only samples where 4 generations all reached IoU = 1.0; rejection sampling between stages keeps items with non-zero reward variance (174k for RL); SFT is LoRA (lr 1e-4, batch 32); GRPO lr 5e-5, batch 8, temp 0.7, 1024 tokens, 8 rollouts, β = 1e-3; reward = 1.0·IoU + 0.5·format `[HTML summary]` — [arXiv 2507.00748](https://arxiv.org/abs/2507.00748)

**2026 templates**
- Part-level grounding RL (Qwen3-VL-4B-Instruct, RL only): `<locate>` reasoning → `<target>` object|part → `<object_hint>` JSON parent boxes (`[]` for object queries) → `<first_answer>` {bbox_2d, point_2d} → `<criticism>` ending "ADJUSTMENT: YES/NO" → `<answer>`; rewards (all normalized to [0,1] or [−1,0]): format, target decision, Hungarian IoU, adaptive L1, point-in-box, compactness/over-prediction penalty, non-repetition, object-hint IoU, part-containment, improvement reward max(0, IoU_final − max(IoU_initial, λ·IoU_baseline)), adjustment-consistency penalty −1, degradation penalty `[HTML summary]` — [arXiv 2607.15374](https://arxiv.org/abs/2607.15374)
- EGM (Qwen3-VL-2B/4B/8B, InternVL3-1B/2B/8B): short 1–3-sentence trace that "analyzes the feature that distinguishes the target object from others" before the box; SFT on 575,208 vanilla traces (RefCOCO train, proprietary-VLM teacher) then GRPO with r = 0.5·IoU + 0.5·1[IoU > 0.5], lr 3e-6, 5 epochs, batch 256, β = 0.005 (Qwen) / 0 (InternVL), full fine-tuning, 8×A100 `[HTML summary]` — [arXiv 2601.13633](https://arxiv.org/abs/2601.13633)
- "Thinking with Visual Grounding" (Gemma3-4B-IT): `<obj> descriptive phrase | [x1,y1,x2,y2] </obj>` or `| [x,y]` inside the reasoning, coordinates in [0,1000]; 19,909 traces / 107,613 groundings distilled from Qwen3-VL-Plus with SAM3 boxes; SFT 6 epochs then GRPO 100 steps × 8 rollouts; reward = 1.0·answer + 0.5·grounding (IoU of box unions, or point-in-mask F1) + 0.1 thinking-format + 0.1 grounding-format `[HTML summary]` — [arXiv 2606.16122](https://arxiv.org/abs/2606.16122)
- H-GRPO (Qwen2.5-VL-3B, SmolVLM-2.2B): each step is a triplet ⟨sub-question, answer, box⟩; process reward via Hungarian matching of predicted steps to reference steps with S_ij = ¼(E + sim_q + sim_a + IoU); R = α·format + β·answer·max(0, S_hs − γ); 10k SFT samples `[HTML summary]` — [arXiv 2606.29915](https://arxiv.org/abs/2606.29915)
- RSGround-R1 (Qwen2.5-VL-3B, remote sensing): `<think>…</think><answer>…</answer>`; 30k CoT-SFT traces from Qwen2.5-VL-72B; GRPO 0.4 epoch; R = format + IoU + 0.1·Gaussian positional reward + spatial-consistency weighting `[HTML summary]` — [arXiv 2601.21634](https://arxiv.org/abs/2601.21634)
- ViSurf (Qwen2.5-VL-7B): `<think>`/`<answer>` JSON `{"bbox_2d", "point_2d"}`; the ground-truth answer is appended to the rollout group (y ∪ {o_j}) with three controls — reformat GT to the model's style, give the GT rollout zero thinking-format reward, and "smoothing" r(y) = mean r(o_j) when the model's best rollout already ≥ GT `[HTML summary]` — [arXiv 2510.10606](https://arxiv.org/abs/2510.10606)

**Technical reports**
- GLM-4.5V grounding output: boxes `[[x1,y1,x2,y2], …]` normalized ×1000 inside `<|begin_of_box|> … <|end_of_box|>` special tokens; missing tokens are "penalized with a minimal reward"; RL grounding reward = "#boxes with IoU > τ divided by total boxes" `[PDF Table of rewards, App. B.3]` — [arXiv 2507.01006](https://arxiv.org/abs/2507.01006)
- Qwen3-VL: coordinates normalized to [0, 1000]; RL stage uses verifiable rewards on grounding among other tasks; a "cold-start agentic dataset comprising approximately 10k grounding" samples is mentioned for the agent stage `[PDF]` — [arXiv 2511.21631](https://arxiv.org/abs/2511.21631)

### Inferences
- Only three published REC formats make the *answer a function of per-candidate verdicts*: Rex-Thinker (trace), CRS (single-token choice with None), VLM-FO1/ChatRex (region-index tokens). All three take candidates from an external detector; none enumerates candidates with the policy itself.
- The reward that the trace actually receives is, in every REC method, on the final box only; the exceptions (TreeVGR, GRIT, ViGoRL, RC-GRPO-II, Faithful GRPO, part-level template) are VQA-style or 2026 work, and TreeVGR shows the failure mode when the intermediate reward has no precision guard (KQ2).
- Rex-Thinker's IoU = 1 matching plus the hint protocol means the box "follows the reasoning" by construction (the model copies a hint), so faithfulness there is a property of the format, not of the model.

- Rex-Thinker's SFT compute (8×A100 ≈ 10 h) and GRPO compute (≈ 112 h) are from the HTML summary and were not re-read in the PDF.

## Key Question 2 — Which ablations separate "format/SFT" from "RL", and what are the concrete deltas on grounding benchmarks?

### Takeaway
Across the REC papers the pattern is stable: **CoT-SFT is where the format and the big in-domain jump come from (+1 to +40 depending on how far the base is from the target format), GRPO on top adds +1 to +6 on positives and generalizes better out of domain, and GRPO without a cold start is worse than CoT-SFT alone at 7B** (UniVG-R1 57.43 vs 64.50; multi-image grounding 17.79 vs 52.41; Rex-Thinker 77.8 vs 82.3 DF1). The one clean "RL-only beats SFT" result on plain REC is VLM-R1 on OOD LISA-Grounding (+8.3 vs −1.7), and Rex-Omni's sampling analysis shows GRPO's detection gain is mostly consistency (best-of-8 oracle of the SFT model already reaches GRPO's COCO F1) plus fixing duplicate/giant boxes.

### Inferences
- "GRPO adds ~+1 to +2 on positives after a CoT cold start" (Rex-Thinker +1.2 DF1, UniVG-R1 +1.65 then +2.0, Ref-R1 +5.2 Acc_p, EGM's RL "majority of improvement" is on top of a 575k-trace SFT) versus "RL-only adds +8 OOD at 3B" (VLM-R1) — the two regimes differ in how far the base already is from the format: when the base can emit the target format, RL-only works; when it cannot (multi-image, candidate hints, MCTS-style traces), RL-only collapses (17.79; "no valid output").
- Rex-Omni's Table 16 is the only direct test of "does RL create capability or sharpen sampling" in a grounding model: on COCO an oracle over 8 SFT samples equals GRPO, on LVIS/Dense200 it does not — i.e. RL is sharpening on easy data and something more on dense/hard data.
- The part-level result (−3.2 RefCOCO avg after RL on a heavy template) and Perception-R1's SFT+RL ≤ RL-only are the two places a structured format demonstrably *cost* plain REC.

### Gaps
- No REC CoT paper reports HumanRef, Ref-L4, ODinW or D3 for its SFT-only checkpoint; the SFT-vs-RL split exists only on the paper's own benchmark plus RefCOCO-family side tables.
- GroundingME numbers exist only for base/tech-report models and for GroundingME's own SFT mixture (KQ5); no SFT-then-RL REC method has been evaluated on it.
- UniVG-R1's "pure RL 57.43" arm uses 21k samples vs 90k for CoT-SFT; the data-matched comparison is 57.43 vs 64.50 (21k).

## Key Question 3 — Does "thinking" help or hurt plain grounding, and is the trace faithful to the box?

### Takeaway
On plain REC, free-form thinking is neutral-to-harmful at every published scale (Qwen3-VL Thinking is 0.1–0.8 below Instruct on RefCOCO avg and 4.9–8.8 below on ODinW-13 at 2B–235B; Perception-R1 −14 on RefCOCO with thinking; GUI-G1 "longer chains lead to worse grounding"; GroundingME thinking −4.4 to −9.3 on Discriminative), while it helps relational/ordinal items (GroundingME Spatial +16.7 to +24.0; RefBench-PRO Relation +1.5/+10.9) and reasoning-grounding OOD sets (LISA, ReasonSeg). Faithfulness measurements are sparse: GCoT answer-grounding consistency is 56.8% for Qwen2.5-VL-7B and 39.0% for 72B; Faithful-GRPO reports standard GRPO raising trace-answer inconsistency from 7.4% to 26.1% while accuracy rises; ViGoRL's coordinates are judged accurate 72.8% of the time; GRIT's box-text correlation is 70–75% vs 85–90% for humans.

### Inferences
- Two different "thinking" costs are documented: a *format/length* cost on short perceptual items (Perception-R1, GUI-G1, MME-CoT stability, attention dilution) and an *object-commitment* cost on same-category discrimination (GroundingME Discriminative down while Spatial up; best-of-16 cannot recover it). The per-candidate structured trace (Rex-Thinker) avoids the second cost by construction and pays a smaller first cost (Interaction −3.0).
- Faithfulness numbers come almost entirely from VQA-with-boxes settings; for REC the only faithfulness-adjacent numbers are GCoT consistency (answer vs box) and the Rex-Thinker hint copying. Nobody has measured "box follows verdicts" on a REC trace.

### Gaps
- No paper runs the same REC model with (i) no trace, (ii) a structured per-candidate block, and (iii) free-form thinking on the same hard set with a false-null column.
- The Qwen3-VL and GLM-4.5V reports do not state whether the Thinking-mode grounding numbers use the same prompt/parser as Instruct; EGM's re-evaluation gives different absolute values (88.3 vs 89.1 for 8B-Instruct).
- Ground-R1's RefCOCO rows for Vision-R1/R1-Onevision come from that paper's own evaluation; no protocol is given.

## Key Question 4 — Does "a fixed output format in SFT activate latent visual reasoning from pretraining"? Support vs contradiction, by model scale.

### Takeaway
The evidence supports a narrower claim: **SFT on a fixed format supplies the emission format and a behavioral prior that RL cannot discover on its own when the format is far from the base's distribution (multi-image, candidate hints, MCTS-style coordinates) — and this is true at 3B, 4B and 7B — but the "reasoning" that SFT installs is largely surface form** (Rex-Thinker's GPT-4o teacher scores 53.2 DF1 without the answer vs the student's 82.3; "SFT or RL?" shows SFT-installed traces lower Qwen2.5-VL-3B from 31.8 to 12.7–21.6 on reasoning; GRIT gets grounded reasoning from 20 examples with RL only at 2–3B). At 2B–4B the small-model-specific findings are: sparse outcome rewards are insufficient without a prior (H-GRPO), free-form thinking hurts (Perception-R1, GUI-G1, Qwen3-VL-Thinking), and structured/grounded templates beat free-form ones (SATORI +12.3, Point-RFT +29.1 SFT / +9.1 RL, Thinking-with-VG +17).

### Cited Findings

**Supports "format must be installed by SFT" (RL cannot find it)**

### Inferences
- The consistent reading across scales: SFT installs *format + decomposition habit* (needed when the format is exotic), RL installs *selection/consistency* (removes duplicates, sharpens sampling, generalizes OOD). "Latent reasoning activation" is not separable from "format installation" in any published REC ablation because no paper trains the format with answer-agnostic traces.
- For a 4B model the strongest published evidence is that a **short, structured, grounded** format (EGM, SATORI, Point-RFT, Thinking-with-VG) is safe and mildly positive, while **free-form thinking** is negative on perception-type grounding.

### Gaps
- No paper separates CoT-SFT from answer-hint distillation (all REC traces — Rex-Thinker, UniVG-R1, Ref-R1, multi-image — are written by a teacher that saw the answer or by best-of-N against GT).
- No 4B REC paper reports base pass@k on hard items before/after format SFT.

## Key Question 5 — Rejection / hard negatives: which formats produce explicit "no match" decisions, how they avoid over-refusal, and the numbers

### Takeaway
Explicit refusal appears as (i) an empty box list after per-candidate elimination (Rex-Thinker: rejection 53.5 → 67.3 from the CoT format alone, → 68.2 with GRPO, at +1.2 DF1), (ii) a "None" multiple-choice option over detector proposals (CRS: Qwen2-VL-7B 5.2 → 62.3 negatives with the None prompt but 79.0 / 27.1 after CRS tuning — positives bought back at the cost of rejection), (iii) a literal "None"/`null` string trained by mixing negatives (GroundingME 2:1 SFT: rejection 0 → 27.9 OOD, Discriminative 61.3 → 40.2, RefCOCOg 88.2 → 83.1), and (iv) RC-GRPO's forced-None rollouts with a −1 penalty for None on positives (Qwen2.5-VL-7B FineCops N-acc 5.3 → 61.1 at P-acc 73.6 → 69.6, versus SFT's 95.4 N-acc at 30.1 P-acc). Every recipe without an explicit over-refusal term pays on positives (Ref-R1 RL lowers rejection 61.5 → 58.2 while raising Acc_p; CRS; GroundingME mixture), and RC-GRPO's α sweep shows the trade-off is one knob.

## Key Question 6 — Applicability to a 4B model trained with LoRA on one 32 GB GPU

### Takeaway
The recipes that already ran at ≤ 4B with modest compute are RC-GRPO (LoRA, Qwen3-VL-4B, 2k samples, 500 steps, 8 generations × batch 8 on 2×A800), GRIT (3B, 20 samples, 200 steps), VLM-R1 (3B, RL-only REC), GUI-G1 (3B, 17k), SATORI (3B), ViGoRL (3B, ~30k SFT traces), H-GRPO (2.2B/3B, 10k SFT), RSGround-R1 (3B, 30k SFT + 0.4-epoch GRPO), Thinking-with-VG (Gemma3-4B, ~20k SFT + 100 GRPO steps) and the part-level template (Qwen3-VL-4B, RL-only). The ones that do not fit are Rex-Thinker's GRPO (~112 h × 8 A100), Rex-Omni's 22M-sample SFT, EGM's 575k-trace SFT with batch 256, Point-RFT's batch-512 SFT, and ViSurf at 7B (81.8 GB per step).

### Cited Findings

### Inferences
- A 4B LoRA GRPO run with 8 rollouts, batch 8, ≤ 1k-token completions is within the envelope RC-GRPO used on two 80 GB cards; on one 32 GB card the same recipe needs gradient checkpointing and a smaller rollout batch, but the sample counts (2k–10k) and step counts (100–500) of the ≤ 4B papers are the right order of magnitude.
- The trace length is the main memory/latency lever: Rex-Thinker's ~560-token traces cost 5.9× latency at 7B; EGM's 1–3-sentence trace gives +0.3 to +0.9 at 2B/4B; a per-candidate block should be kept to the candidate count × clause count.
- Because Qwen3-VL-4B-Instruct already refuses on gRefCOCO (77.2) but not on GroundingME (0.0), any rejection recipe's headline delta on it will be small in-distribution and unmeasured out-of-distribution.

### Gaps
- No paper reports peak GPU memory for a 3B–4B GRPO run with LoRA; the only memory figure is ViSurf's 81.8 GB at 7B full fine-tuning.
- No published LoRA-vs-full comparison exists for the RL stage on REC (only for the CoT-SFT stage, at 7B).
