# 创新候选：能 beat 已有工作的方法（2026-09-24）

承接 `notes/DESIGN-EVIDENCE-GATED-GROUNDING-2026-09-24.md`。那份设计的创新性只够 PoC；这份文档回答"怎样才能既有创新又能 beat 已有工作"。先给诊断，再给五个候选创新点，再合成一个方法，最后给新的评测主指标和诚实的风险。不开始实验。

## 0. 要 beat 的是什么

| 场地 | 现有最好 | 代价 |
|---|---|---|
| GroundingME Rejection（201 条，人改假一个从句） | 25 个公开模型里 20 个恰好 0.0；零样本最好 9.5（32B thinking，且伴随 Discriminative 下降，是先验位移） | — |
| 同上，GME 自己的 2:1 负样本 SFT（8B） | 27.9 | Discriminative 61.3→40.2，Limited 36→17，RefCOCOg 88.2→83.1 |
| 我们昨夜的坐标流配方（4B） | 30.8 | 正样本误拒 36.7%；四种配方全在"拒答率 ≈ 误拒率"一条线上 |
| HumanRef Rejection（Rex-Thinker，7B，带检测器候选） | 67.3（CoT-SFT）/ 68.2（+GRPO） | 无候选提示时靠过度拒答到 71.7 |
| FineCops-Ref / gRefCOCO 无目标（RC-GRPO，Qwen3-VL-4B） | N-acc 58.3→71.3 / 77.2→85.3 | 正样本约持平（4B），7B 上 P-acc −4 |

"beat"的定义：GME 拒答明显高于 27.9，同时 Discriminative / Limited / Spatial / RefCOCO 持平或上升；这在文献里还没有出现过。若同一配方在 HumanRef 上不用检测器候选就接近 68，故事就不限于一个 benchmark。

## 1. 诊断：两个瓶颈，现有方法各解一个

昨夜和 datagen 的数据合起来说的是一件事：

- **感知瓶颈。** 被改假的细节在全局分辩率下看不见：验证优先的 prompt 在 4B/8B 上都把假细节标"true"；同一个 8B 模型，给它一个原图分辩率的裁剪加一条孤立子句，91% 能判出假。这是我们量到的最大效应。
- **决策瓶颈。** 即使证据在，null 也只是坐标流里的一个 token，没有任何东西要求它被证明。正负样本作为独立样本训练时，模型用"题目难度"就能拟合，于是 p(null) 对 GME 拒答项 vs 正样本的 AUROC 低于随机。

已有方法各解一个：Rex-Thinker 有决策结构（逐候选核对）但没有裁剪，在全局分辩率下核对；DeepEyes / Mini-o3 / Chain-of-Focus 有裁剪但没有拒答也没有核对结构；RC-GRPO 只有奖励不对称。没有方法同时解两个，也没有方法保证"拒答必须有证据"。同时解两个瓶颈、并让证据成为拒答的必要条件，是 beat 的路径。

第三个隐含约束是**迁移**：我们的训练数据是 Gemini 写的、物体较大的合成场景，GME 是人写的 54 词段落、物体中位只占图面 5%。昨夜域内 AUROC 0.83–0.85 但 GME 0.33–0.39，说明学到的东西不迁移。能迁移的是基座本来就会的技能：短表达式定位、裁剪上的属性识别、多目标检测。方法应当**组合**这些原生技能，而不是靶 800 条样本教一个新技能。

## 2. 五个候选创新点

每条：洞见 / 为什么能赢 / 新在哪 / 风险 / 最便宜的验证。

### A. 拒答必须指控：答案由核对表推导，模型不自由生成 null

- **洞见**：过度拒答之所以能发生，是因为 null 可以不付出任何解释就输出。若答案是核对表的确定性函数（没有候选被明确标 no 的 → 不能 null；恰有一个全通过 → 它的框；全部各有至少一条明确 no → null），盲拒在结构上不可能。null 必须指名一条假子句、落在具体候选上。
- **为什么能赢**：正样本的误拒率变成一个可测、可训的感知量——"把真子句标成 no"的比率。它有过程标签，能被直接监督和奖励；而"模型什么时候想拒"是不可监督的。
- **新在哪**：Rex-Thinker 由模型自由生成答案，只在训练数据上过一遍一致性过滤（推理时一致率约 90%）；RC-GRPO 的"说出错在哪句"是加分项。这里"无指控不拒答"是硬约束，且指控本身成为可评测输出（见 §4 指控准确率）。
- **风险**：unclear 的处理（不能算 no，否则模糊即拒）；多候选全通过时的择一规则。
- **验证**：不需要训练。用基座 + 用户格式的 prompt 零样本跑自家 48 条验证集和 GME 开发子集，把"模型自己写的答案"和"从表推导的答案"各算一次拒答与误拒，看推导规则单独改变了什么。

### B. 最小对作为训练单位：同图改一句、同句改图，以对计分

- **洞见**：独立样本可以被难度阈值拟合，这是那条线的来源。共享图片、只差一个子句的一对，把难度固定住，剩下的唯一变量就是那个子句；共享文本、只差一个像素区域的一对（编辑图像把子句改假），把文本捷径完全堵死。训练目标以对为单位：SFT 里核对表的 verdict 在对内做 margin；GRPO 里正负孪生题进同一个 batch，一对里正样本给对框、负样本正确拒答才得分，盲拒和盲框在对上都得零。
- **为什么能赢**：直接消灭我们量到的失败机制。以对计分的奖励下，那条"拒答率 ≈ 误拒率"的线是零分线。
- **新在哪**：诚实地说，图像编辑负样本不是新的——FineCops-Ref 已用 PowerPaint 按框修图造负样本，CVPR 2024 的 Counterfactual REC 用 BERT 改属性词造反事实查询。新的是**把对作为损失和奖励的单位**（配对 margin、对级 GRPO 奖励），以及把它用于生成式定位模型的拒答训练。Winoground 类工作只把最小对用于评测。
- **风险**：对级奖励在训练早期可能双零无梯度（先只门控 null 一侧，再对称）；图像编辑要下载编辑模型、要 Gemini 核对编辑是否成功且别处未动。我们已有 GME 移除物体的编辑链，改属性是它的近邻。
- **验证**：先用文本对（数据已有）：把昨夜的 RC-GRPO 改成对级奖励重跑一次，看域内 AUROC 之外 GME 的 AUROC 是否离开 0.33–0.39。

### C. 核对在裁剪上做，过程奖励来自看得见高分辩率裁剪的判官

- **洞见**：我们最大的效应量（91% vs 随机）来自"裁剪 + 孤立子句"。核对链里每个候选的核对应当发生在它的原图分辩率裁剪上，而不是全局视图上。训练时，过程奖励来自一个**只在训练时存在、看得见裁剪的判官**（8B 或 Gemini，用自家数据）：判官比策略知道得多，这正是 PRM 类奖励唯一有效的条件（VisualPRM、VL-PRM、Perceval 的共同教训）。策略学到的是要么从全局视图抽出同样的证据，要么学会在该放大时放大。
- **为什么能赢**：Rex-Thinker 在全局分辩率核对，看不见 GME 尺度的细节；裁剪类方法没有拒答。把两者放在一起是调研确认的空白。
- **新在哪**：zoom + 核对 + 拒答的组合；"特权信息判官"给过程奖励（策略看不到判官看到的东西）。后者在 RL 里有先例（learning by cheating），在 VLM 定位上没有。
- **风险**：两轮、显存、延迟；outcome-only RL 会消灭工具（调研里反复出现），所以工具只能通过"更准的 verdict"间接获利，绝不能有无条件加分（Thyme 教训）。
- **验证**：设计文档 §5 的分辩率测试：把自家场景缩放到 GME 的物体尺度，比较全局 vs 裁剪下 4B 的逐子句核对准确率。这一个测试决定 C 是主线还是不要。

### D. 记录观察值，而不是回答 yes/no

- **洞见**："帽子是红的吗？"是引导性问题，VLM 对它有系统性的 yes 偏差（POPE 一系工作），我们自己也量到假细节被标 true。让模型对每条子句先写下**它看到的值**（"帽子：蓝"），verdict 由观察值与声称值的比对得出。生成不带预设；同时，一个"no"必须附带一个替代值，假指控比空口说 no 难得多——这直接压低 A 里最危险的量（真子句被标 no；零样本 8B 每条 18%，五条子句叠起来就是六成的误拒风险）。
- **为什么能赢**：同时打两个东西：yes 偏差（漏判假子句）和假指控（误拒）。它们是拒答任务的两类错误，一个格式选择同时约束两边。
- **新在哪**："先描述再比对"在幻觉研究里有零散的 prompting 先例，作为可训练的核对格式、并把"替代值"当作拒答的必要条件，没见过。
- **风险**：观察值的标签从哪来——有：假子句的原文就是真值（改假前的那条），真子句的观察值就是声称本身；训练轨迹可以从标签渲染。位置关系类子句的"观察值"要定义好（"在红车的左侧"→"在红车的右侧"）。
- **验证**：零样本对比两种问法在自家负样本上的假子句检出率与真子句误判率，半小时。

### E. 先承诺，再审计，失败才枚举

- **洞见**：GME 的负样本是"几乎对"的：k 条子句里 k−1 条对目标为真，基座在全部 201 条上以 p(box) ≥ 0.9996 把框打在那个"本意物体"上。所以拒答不需要一开始就枚举全部候选：先让模型按原生技能承诺一个框，再对这个框做审计（C+D），全部通过就答；某条不通过才升级——枚举其他同类候选、审计它们、择一或 null。
- **为什么能赢**：两件事。其一，正样本的默认路径就是基座路径，任何偏离都必须经过一次明确指控，这是"正样本不掉"的结构性保证，而不是靠奖励平衡。其二，GME 正样本的失败结构是**选错物体**而非定位不准（我们的失败结构分析）；审计恰好抓的就是"承诺的物体不满足某条"，升级恰好就是重选。同一个机制既做拒答也修正样本，这是唯一可能让 Discriminative **上升**而不只是持平的路径。
- **新在哪**：懒枚举的控制结构（承诺→审计→升级）；把拒答和重选统一成"审计失败后的两种出口"。Rex-Thinker 总是全枚举，成本高且候选靠检测器。
- **风险**：审计的假 no 率是全部风险的根（见 D）；升级步的候选召回。
- **验证**：基座框 + 裁剪审计的零样本版本就是 K2（设计前身里定义过）：在 GME 开发子集上从缓存的基座框做审计，看拒答项 vs 正样本的项级 AUROC。

## 3. 合成：承诺–审计–升级（Commit–Audit–Escalate）

一个模型，一条轨迹，格式仍是用户提出的结构化核对表，只是顺序和出口变了：

```
<commit>{"bbox_2d":[…]}</commit>                       ← 原生定位，基座路径
<audit id="c0" bbox="[…]">                            ← 在该框的原图分辩率裁剪上（C）
  1 帽子颜色: 声称 红 / 观察 蓝 → no                     ← 观察值格式（D）
  2 手持物: 声称 伞 / 观察 伞 → yes
  3 位置: 声称 红车左侧 / 观察 红车左侧 → yes
</audit>
<escalate>                                            ← 只在审计失败时出现（E）
  <audit id="c1" bbox="[…]"> 1 … → no  2 … → yes  3 … → no </audit>
  <audit id="c2" bbox="[…]"> 1 … → yes 2 … → no  3 … → yes </audit>
</escalate>
<answer>{"bbox_2d": null}</answer>                    ← 由审计表推导（A），非自由生成
```

正样本的常见路径只有 commit + 一个全通过的 audit，短。训练：SFT 在标签渲染的轨迹上（候选框、子句、逐候选逐子句 verdict、改假前原文作观察值，全部已有）；GRPO 以最小对为单位计分（B），null 只有在指控落在被改假那条子句上才得分，过程奖励来自看得见裁剪的判官（C），候选框 F1 防枚举刷分，无任何无条件加分。

## 4. 新的评测主指标

- **同图最小对双正确率**：一对里正样本框对且负样本正确 null 才算对。这个数字对那条交换线免疫（盲拒、盲框都是 0），对文本捷径免疫（图像对里文本相同）。GME 现有协议把拒答和正样本分开打分，正是它让 2:1 SFT 那种"用 −21 分 Discriminative 换 +27.9 拒答"看起来像进步。
- **指控准确率**：拒答时指名的子句是否就是被改假的那条。这是拒答任务第一次有"为什么拒"的可评测输出；自家数据直接可算，GME 上若能确定被改假从句也可算。
- 继续报：正样本误拒**计数**按尺寸分层、灰图差、文本地板、逐子句假 no 率。

## 5. 与已有方法的对照

| | 决策有结构 | 核对在裁剪上 | 拒答须有证据 | 以对为单位训练 | 正样本受结构保护 |
|---|---|---|---|---|---|
| GME 2:1 SFT | ✗ | ✗ | ✗ | ✗ | ✗ |
| RC-GRPO | ✗ | ✗ | 加分项 | ✗ | 奖励平衡 |
| Rex-Thinker | ✓ | ✗ | ✗（一致性过滤） | ✗ | ✗ |
| DeepEyes / Mini-o3 | ✗ | ✓ | 无拒答 | ✗ | — |
| 承诺–审计–升级 | ✓ | ✓（若测试支持） | ✓ 结构性 | ✓ | ✓ |

## 6. 诚实的风险

1. **假指控率**是一切的根。零样本 8B 每条真子句 18% 误判，五条叠加即六成误拒。D 的观察值格式、SFT 的过程标签、−1 的误拒惩罚都对着它；它是第一个要看的数字，SFT 后不降到个位数就没有后文。
2. **4B 拆不好人写的 54 词段落**。拆条件是 LLM 技能，4B 未必稳；可用基座零样本在 GME 开发子集上拆 50 条人看。
3. **图像编辑对的成本与许可**：编辑模型要下载（先问），只编辑自家场景，绝不碰 GME 图。
4. **两轮的工程与显存**：只在分辩率测试说必要时才付这个成本。
5. **创新性的边界**：图像编辑负样本、逐候选核对、zoom 工具各有先例；我们的主张必须落在"组合 + 结构性拒答约束 + 对级目标 + 新指标"，并由消融表证明每一项各自贡献。若消融显示门控与对级奖励只带来一两分，就退回 PoC 定位。

## 7. 推荐

主线选 §3 的合成方法，但由三个不训练的测试决定它的形态（全部可在一天内跑完）：

1. 分辩率测试（决定 C 是否进主线）。
2. 观察值 vs yes/no 两种问法的假子句检出率与真子句误判率（决定 D）。
3. 基座框 + 裁剪审计的零样本项级 AUROC（K2；决定 E 的承诺步是否可靠）。

三个测试之后，先做格式 SFT 与"对级奖励 vs 独立奖励"的一行消融（B 用现有文本对，不需新数据），这是整篇论文最关键的一行。图像编辑对作为第二阶段。
