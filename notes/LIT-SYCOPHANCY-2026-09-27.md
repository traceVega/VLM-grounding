# 文献速查：模型顺着声称胡说 / 描写与声称不符，业界怎么解（2026-09-27）

背景：RL 第二轮的失败原文显示，被描述实例的审计把声称换个说法当作 seen（复述回声），被改假的条款也判 match。用户否决了"盲描述"方案，要求先看业界通行做法。

## 现象在文献里叫什么
- VLM 谄媚（sycophancy）/ 引导式提问偏差 / yes 偏置。引导句（"Is there a dog? It seems like there isn't"）让 POPE 掉 12–42 分；语气越强越谄媚（arXiv 2408.11261）。
- MM-SY（arXiv 2410.11302）：谄媚集中在高层；高层对图像 token 的注意力不足是主因；SFT/DPO 后高层图像注意力上升。

## 业界的修法（按主流程度）
1. 平衡的负指令数据（LRV-Instruction, arXiv 2306.14565）：三类负样本——不存在物体、**存在物体但属性被改**、知识被改；目标是拒绝假前提；正负要平衡，负太多会过度怀疑。存在物体被改属性正是模型最常胡说的一类，与我们 GME 的失败一致。
2. 幻觉对比的偏好优化，学分打到片段/短语级：RLHF-V（片段级人工纠错 → 稠密 DPO，1.4k 样本降幻觉 34.8%）、RLAIF-V（arXiv 2405.17220：把回答拆成原子声称→逐条 yes/no 核验→分数 = −被否声称数；**去混淆采样**：同一模型同一提示不同种子，配对只差可信度不差风格；拆解核验与人一致 96.7% vs 整体判 66.7%）、HA-DPO（风格对齐的正负对）、POVID（往文本里注入幻觉 + 图像扰动造负例）、HALVA（ICLR 2025：短语级替换造对，**只压低幻觉短语相对正确短语的概率**，保住通用能力）。
3. 可验证的忠实度评分进 RL（V-Rubrics, arXiv 2608.25580）：只给最终答案打分会把不同失败"压成一个信号"、放大捷径推理；按实例生成评分项——视觉忠实（陈述被图像支持）、推理一致（结论跟随观察）、指令遵循——R = α·R_ans + (1−α)·R_rubric，8B 上比 SFT 高 2.7/6.8。
4. 指代表达拒答的直接同行（Teaching MLLMs to Say No / RC-GRPO, arXiv 2608.04698，基座含 Qwen3-VL-4B）：负样本来自 FineCops-Ref（对属性/关系/类别做**细粒度改写 + 图像编辑**，正负 3:1）；奖励：正样本 IoU≥0.5 +1、错框 0、判空 −1；负样本判空 +1；采样里没有 None 就用约束束搜索强制一条 None 以便算优势；**负样本优势乘 α=0.5 防过度拒答**；第二阶段"说明不符之处"加分至多 0.8。gRefCOCO：P 64.9 / N 71.5（SFT ≈ 30 / 95）。
5. 谄媚训练的已知副作用：MM-SY 里 SFT（1k 合成样本）把谄媚 94.6→25.4 但接受合理纠正掉到 42%，DPO 到 5.4% 但纠正接受率 1.7%（顽固）；"Sycophancy Suppression Can Impair Rational Updating"（arXiv 2608.26511）：两种行为共用神经元，要当成选择性问题。对应到我们：过度拒答（正样本判空、灰图差）就是同一条权衡线。
6. 推理期技巧（对比解码 VCD/ICD、问句中性化后对比 logits）：POPE 上的增益被证明是伪影——单向把分布往 yes/no 推、加合理性约束等价于贪心（"The Mirage of Performance Gains", arXiv 2504.10020），生成类基准无增益。不采用。注意：问句中性化对比（arXiv 2408.11261）和 CoVe 的分解核验（arXiv 2309.11495）与被否决的"盲描述"同族，仅记录。
7. 机理侧：P²-DPO（arXiv 2606.03376）认为幻觉源于注意区域的感知瓶颈；MM-SY 的训练无关补救是放大高层（16–32 层）图像 token 注意力。可作诊断，不作方法。

## 对我们的含义
- 我们已有的：正负 1:1、标签注入（= 偏好对的正侧）、分段优势、对被改假条款的正确指控加分（= RC-GRPO 的说明加分）。
- 缺的、且有标准做法可循的：(a) **对幻觉短语本身的稠密惩罚**（HALVA / RLHF-V / V-Rubrics 的"视觉忠实 + 推理一致"）——被描述实例审计里被改假那一行若 seen 只是复述声称（含改后值、不含原值）却判 match，就在该审计片段扣分；全部可由标签/规则验证，不用裁判模型；(b) **负样本的生成配方**（FineCops-Ref / LRV 的"存在物体改属性/关系/数量/文字，一处改动"）——我们的条款库翻转是它的粗版本，要上量与多样性；(c) 负样本优势缩放 α（RC-GRPO）作为过度拒答的旋钮。
