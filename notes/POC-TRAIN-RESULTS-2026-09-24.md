## 0. 评测协议

- 全量评测（`eval_suite`，tag `base4b` / 最终候选）：GME 1,005 条全集、GME 灰图对照 300 条（201 拒答项 + 100 分层正样本，灰图）、自家验证 48 条（18 场景）、灰图 48 条、RefCOCO/+/g val 各 300。
- 筛选评测（tag `scr_*`）：201 拒答项全部 + 150 分层正样本、GME 灰图 252、自家 48、灰图 48、RefCOCO 各 60。基线在**同一批条目**上重算（`screen_compare.py`），所以两列可直接比。
- 灰图对照的读法：基座在灰图上对拒答项和正样本几乎一律输出 null（98.5% / 97.0%），所以"灰图 null 率接近真图"不是捷径信号；**捷径信号是灰图上拒答项与正样本 null 率之差**（纯文本驱动的拒答会让拒答项的灰图 null 率高于正样本）。
- 解析器把 null 记为 `output_type == "none"`；误拒率按 none/refusal 计。GME 拒答项按官方规则：非框即对。

## 3. 结果（筛选评测；基线列为同批条目）

### 3.1 SFT v1（计划配方：LoRA r16, lr 1e-4, 3 epoch, 负样本 30%）— 淘汰

解锁曲线（验证 15 负 / 33 正）：第 20 步负样本 null 率 0.67、p(null) 中位 0.65；**同时正样本误拒 0.33、准确率 0.85 → 0.64，之后 80 步不再恢复**（最终 0.73 / 0.61 / 0.33）。

| 指标 | 基线@同批 | SFT v1 |
|---|---|---|
| GME 拒答准确率 | 0.000 | **0.308** |
| GME 非拒答准确率（150） | 0.447 | 0.300（误拒 0.367） |
|   Limited / Spatial / Discriminative | 0.446 / 0.393 / 0.526 | 0.286 / 0.196 / 0.474 |
| GME 灰图 拒答项 / 正样本 null 率 | 0.985 / 1.000 | 1.000 / 1.000 |
| 自家 负样本拒答 / 正样本准确率 / 误拒 | 0 / 0.849 / 0 | 0.733 / 0.606 / 0.333 |
| RefCOCO / + / g | 0.917 / 0.767 / 0.917 | 0.833 / 0.667 / 0.817（误拒均值 0.106） |

读法：拒答 30.8 与 GroundingME 论文里 2:1 SFT 的 27.9 同量级，代价也同形（非拒答 −15、RefCOCO −8～−10）。误拒的 55 条正样本里 36 条基座本来就框错，19 条基座框对的被拒；小物体最重（Limited/small null 75%）。null 通道学成了"不确定就拒"，不是"描述不满足才拒"。文献（RC-GRPO 表 2：纯 SFT P-acc 73.6 → 30.1）的预测在这里重现。

### 3.2 单阶段 GRPO（从基座起，ViSurf 式真值注入，α=0.5，误拒惩罚 −0.5，lr 5e-5，2 epoch）— 曲线

| 步 | 负样本 null | p(null) 中位 | 正样本准确率 | 正样本误拒 |
|---|---|---|---|---|
| 15 | 0.20 | 0.047 | 0.82 | 0.03 |
| 60 | 0.13 | 0.037 | 0.85 | 0.00 |
| 90 | 0.53 | 0.56 | 0.76 | 0.06 |
| 105 | 0.60 | 0.87 | 0.70 | 0.09 |

第 105 步进程随会话重启中断（adapter 已保存）。比 SFT 温和得多，但第二个 epoch 里正样本开始下滑；−0.5 的误拒惩罚不够。

第 105 步 adapter 的筛选评测：GME 拒答 0.154（p(null)≥0.1 比例 0.279）、非拒答 0.380（误拒 0.173；Limited 0.411 / Spatial 0.304 / Discriminative 0.447）、自家 负 0.600 / 正 0.697 / 误拒 0.091、RefCOCO 0.850 / 0.750 / 0.917（误拒 0.044）、GME AUROC 0.389。与 RC-GRPO 同一条线。


### 3.3 SFT v2（v1 + 193 条跨场景负样本 + null unlikelihood 1.0）— 淘汰

曲线：第 20 步负样本 null 0.13（比 v1 慢），第 40 步 0.67；正样本误拒最高 0.12，最终负 0.67 / 正 0.79 / 误拒 0.12。

| 指标 | 基线@同批 | SFT v1 | SFT v2 |
|---|---|---|---|
| GME 拒答准确率 | 0.000 | 0.308 | 0.139（p(null)≥0.1 的比例 0.209，v1 是 0.707） |
| GME 非拒答准确率（150）/ 误拒 | 0.447 / 0.040 | 0.300 / 0.367 | 0.380 / 0.187 |
|   Limited / Spatial / Discriminative | 0.446 / 0.393 / 0.526 | 0.286 / 0.196 / 0.474 | 0.375 / 0.321 / 0.474 |
| 自家 负拒答 / 正准确 / 误拒 | 0 / 0.849 / 0 | 0.733 / 0.606 / 0.333 | 0.667 / 0.788 / 0.121 |
| RefCOCO / + / g | 0.917 / 0.767 / 0.917 | 0.833 / 0.667 / 0.817 | 0.850 / 0.733 / 0.800（误拒 0.067） |

读法：unlikelihood 项确实压住了误拒（0.367 → 0.187），但拒答也掉到 13.9；"远"负样本（整句在另一张图上不成立）教的是"完全不匹配才拒"，没迁移到 GME 的"只差一个细节"。自家验证负样本拒答率 0.67 与 GME 拒答 0.14 的落差说明域内解锁 ≠ GME 迁移。

### 3.4 RC-GRPO on SFT v1（强制 null 注入、α=0.5、误拒惩罚 −1、lr 2e-5、1 epoch = 65 步）

曲线：起点是 SFT v1 的终态（负 0.73 / 正 0.61 / 误拒 0.33）；第 15 步误拒降到 0.09、正样本 0.76；第 30 步负 0.73 / 正 0.73 / 误拒 0.12；终态 0.73 / 0.67 / 0.15（15 负 33 正，抖动大）。

| 指标 | 基线@同批 | SFT v1 | SFT v2 | RC-GRPO(v1) |
|---|---|---|---|---|
| GME 拒答准确率 | 0.000 | 0.308 | 0.139 | 0.144（p(null)≥0.1 比例 0.199） |
| GME 非拒答准确率（150）/ 误拒 | 0.447 / 0.040 | 0.300 / 0.367 | 0.380 / 0.187 | 0.393 / 0.153 |
|   Limited / Spatial / Discriminative | 0.446 / 0.393 / 0.526 | 0.286 / 0.196 / 0.474 | 0.375 / 0.321 / 0.474 | 0.357 / 0.321 / **0.553** |
| 自家 负拒答 / 正准确 / 误拒 | 0 / 0.849 / 0 | 0.733 / 0.606 / 0.333 | 0.667 / 0.788 / 0.121 | 0.733 / 0.667 / 0.151 |
| RefCOCO / + / g | 0.917 / 0.767 / 0.917 | 0.833 / 0.667 / 0.817 | 0.850 / 0.733 / 0.800 | 0.833 / 0.733 / 0.900（误拒 0.056） |

读法：RL 阶段按设计把误拒压回去了（GME 误拒 0.367 → 0.153，Discriminative 反超基线），但拒答也从 30.8 回到 14.4——与 SFT v2 落在同一条权衡线上。

### 3.5 关键发现：GME 上的 null 不区分拒答项和正样本

三个模型在 GME 上"拒答项 null 率"与"正样本误拒率"几乎相等（30.8 vs 36.7、13.9 vs 18.7、14.4 vs 15.3）：null 在 GME 上按**条目难度**触发，不按"描述是否被满足"触发。域内（自家验证）却有区分（负 0.73 vs 正误拒 0.15）。也就是说 78 条训练负样本解锁了 null 通道并教会了域内的翻转检测，但**没有把"逐子句核对"迁移到 GME**。AUROC 见下。

决策 token p(null) 的 AUROC（同批 201 拒答项 vs 150 正样本；自家验证 15 负 vs 33 正）：

| 模型 | GME 拒答项 vs 正样本 | GME 拒答项 vs Discriminative | 自家 负 vs 正 | GME 拒答项 / 正样本 p(null) 中位（log10） |
|---|---|---|---|---|
| 基座 | 0.262 | 0.409 | 0.615 | −17.5 / −14.9 |
| SFT v1 | 0.378 | 0.452 | 0.834 | −0.5 / −0.4 |
| SFT v2 | 0.348 | 0.415 | 0.851 | −2.4 / −1.7 |
| RC-GRPO(v1) | 0.334 | 0.414 | 0.830 | −3.0 / −2.0 |

**GME 上全部低于 0.5**：训练后的 null 在 GME 正样本上的质量反而高于拒答项（正样本里小物体、空间关系项更"难"）。域内 0.83–0.85。结论：在这份数据上调损失/奖励只能沿"拒答↔误拒"这条线滑动，不能让 GME 拒答单独上升；瓶颈是"逐子句核对"没有迁移，不是优化。与 2026-09-16 深度调研的 D1/D2 一致（p(null) 在 GME 负样本上无缺席信号；模型不核对从句）。

## 4. 四种配方，一条权衡线

| 配方 | GME 拒答 | GME 非拒答（150，基线 0.447） | GME 误拒 | RefCOCO 均值变化 | GME AUROC |
|---|---|---|---|---|---|
| SFT v1（lr 1e-4, 3 ep） | 0.308 | 0.300（−14.7） | 0.367 | −9.3 | 0.378 |
| SFT v2（+跨场景负样本 +UL） | 0.139 | 0.380（−6.7） | 0.187 | −7.2 | 0.348 |
| RC-GRPO on v1 | 0.144 | 0.393（−5.4） | 0.153 | −4.5 | 0.334 |
| GRPO 基座起（ViSurf 式）@105 | 0.154 | 0.380（−6.7） | 0.173 | −2.8 | 0.389 |

四个点上 "GME 拒答率 ≈ GME 正样本误拒率"。没有一个满足预设判据（非拒答掉 ≤5、RefCOCO 掉 ≤3、拒答显著上升）。最接近的是 RC-GRPO（Discriminative +2.7，误拒 15%），但它的 14.4 拒答与 15.3 误拒是同一个东西。

## 5. 结论与下一步

1. **数据能解锁 null，不能教会核对。** 78 条近失负样本在域内把 null 通道打开（验证集负样本 0.6–0.73 拒答、AUROC 0.83–0.85），但在 GME 上 p(null) 与"拒答项/正样本"标签负相关（AUROC 0.26–0.39）。任何 GME 拒答增益都伴随同等的正样本误拒。
2. **配方层面已经试过的杠杆**（negative ratio、unlikelihood、决策 token 权重、RC-GRPO 强制 null + 误拒惩罚、ViSurf 真值注入、跨场景负样本）只改变在权衡线上的位置。
3. **文献对照**：RC-GRPO 论文里 Qwen3-VL-4B 在 FineCops-Ref/gRefCOCO 上 N-acc 58/77 起步、训练后 71/85 且正样本不掉——那是易负样本（类别/属性置换、单从句）；GroundingME 是 54 词长描述里改一个从句，GroundingME 自己的 2:1 SFT 也只有 27.9 且非拒答 −20。我们在 4B 上用 300 条数据复现了同样的天花板。
4. **下一步不是继续调 SFT/GRPO，而是换机制**（对应 2026-09-16 调研的 A/B/F 簇）：(a) 让核对进入输出——Rex-Thinker 式"先逐条核对再答"的 CoT 目标，本夜的 verify-first 探针（§6）显示 4B/8B 零样本都不区分，所以核对能力得靠逐子句监督训出来，不能只靠改输出格式；(b) 负样本按 GME 四个子轴（Appearance / Component / Text / State）和稀释度分层挖掘，规模到千级，并配上"难但在场"的正样本（小物体、空间关系）压住"不确定就拒"；(c) 或者把 presence 判断从坐标流里拆出来（两轮 / presence head）。

## 6. 探针：verify-first 提示（基座 4B，零样本，非 benchmark 协议）

提示 = GME 原 prompt + "先逐条核对（每条 true/false），任一细节对所有候选都为假则无匹配，最后一行输出 JSON"（`configs/prompts/grounding_qwen3vl_verify_first.txt`，max_new 320）。同批 201 拒答项 + 150 正样本。

| | 基座（原 prompt） | 基座（verify-first） |
|---|---|---|
| GME 拒答准确率 | 0.000 | 0.109（null 18 + 不可解析 4） |
| GME 正样本准确率 / 误拒 | 0.447 / 0.040 | 0.333 / 0.153（不可解析 7） |
|   Discriminative / Limited / Spatial | 0.526 / 0.446 / 0.393 | 0.395 / 0.357 / 0.268 |

读法：显式核对也不区分（拒答 10.9 ≈ 误拒 15.3），且正样本掉 11 点。看输出：框住拒答项时模型把被改假的细节标成 true（"Inside the helmet, a red gas mask is visible – true"）；偶尔发现不一致时也会写成 "true (she is wearing a white cap, not red; this is false)"。**4B 在评测分辨率下感知不到/核对不出被改假的细节**，这是 2026-09-16 调研里的 D2b（不可感知）而非 D2a（可感知但忽略）——至少对相当一部分条目如此。所以"把核对写进输出"的 CoT 目标在 4B 上没有零样本上界可依托；要么换更大的模型做核对，要么用逐子句的监督把核对能力本身训出来。

同一探针在 Qwen3-VL-8B-Instruct 基座上（零样本）：拒答 0.144（null 24 / 201），正样本 0.347、误拒 0.147（Discriminative 0.500 / Limited 0.304 / Spatial 0.286），不可解析 13。**8B 也是"拒答率 ≈ 误拒率"**：显式核对在 8B 上零样本同样不区分。
