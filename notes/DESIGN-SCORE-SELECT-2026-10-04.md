# 设计方案：逐条打分，择优或拒答（2026-10-04）

取代 `DESIGN-AAV-2026-10-01.md`。一句话：模型先直接定位、再提几个备选，然后逐条条件给每个候选打分（概率）；选总分最高的候选，最高分过不了门槛就拒答。打分能力用标签确定的数据做监督训练，数据量从现在的不到 900 题放大到 3,000 题和 6,000 题两个点。

## 一、目标与依据
目标：拒答明显提升，正样本不掉（能涨更好），通用能力不受损；全程一个训练后的模型。

| # | 结论 | 证据 | 设计含义 |
|---|---|---|---|
| 1 | 第一个答案的问题已解决 | 训练后的模型用普通提问直接定位：RefCOCO 87.7 / 83.3 / 87.0（基座 90.3 / 84.3 / 87.0），PR 正样本 76.0（74.8），GME 38.4（39.8） | 第一步 = 直接定位 |
| 2 | 剩下的损失全在核查 | 答对的第一候选被否决：RefCOCO 4.9 / 13.6 / 18.4%，PR 关系类 31.6%；答错的第一候选被放行 64–78% | 核查在人写的描述上没有分辨力，要直接训练它 |
| 3 | 候选里有正确对象的比例远高于基座的答案 | GME 73.2 vs 41.0；RefCOCO+ 92.0 vs 84.3；RefCOCOg 93.0 vs 87.0；PR 交互类 92 vs 64、关系类 90 vs 74 | 核查不该只否决：按分数在候选里择优，正样本有超过基座的空间 |
| 4 | 误否决来自较真、比较级和拆条件 | RefCOCO+ / g 上 77 个误否决样例："黄色沙发"判"米色，不符"；"最后一头大象"单看一个候选无法判断 | 用人写的描述训练；用分数在候选之间比较，而不是逐个硬判 |
| 5 | 我们的数据量比可比工作少 | 同为 4B + LoRA 的 RC-GRPO：500 条时过度拒答，2,000 条持平；我们 RL 每轮 324 题，SFT 552 题 | 放大到几千题，用两个点看是否持平 |
| 6 | 同类工作的拒答主要来自监督阶段，RL 加得很少 | Rex-Thinker 53.5 → 67.3（SFT）→ 68.2（RL）；Ref-R1 SFT 后 61.5、RL 后 58.2 | 主要训练放在监督阶段；RL 只管监督管不到的部分 |
| 7 | 小规模奖励信号改不动核查 | RL12 的逐行奖励只在训练风格的描述上有效（GME 每行误判 4.2 → 1.7%），RefCOCO+ / g 仍是 11% | 标签直接作用在判定概率上，不靠采样 |

## 二、机制
1. 直接定位：模型回答普通的定位提问，得到第一个候选。
2. 提备选：模型写出条件（原子声称），并列出至多 3 个备选框。
3. 逐条打分：每个候选单独一个上下文（标框全图 + 特写），逐条写"声称 | 看到 | 判定"；同时读出判定处"符合 / 不符 / 不确定"的概率。候选的通过概率 = 各条都不被判"不符"的概率之积。
4. 择优或拒答：选通过概率最高的候选；最高的也低于门槛 → 答"没有"。门槛在开发集上定，一次评测就能画出"正样本 vs 拒答"的整条曲线。
5. 早停：第一个候选的通过概率很高时不再核查备选。

和上一版的区别：上一版取"第一个没有被否决的候选"，顺序决定答案，核查只可能让正样本变差；这一版用分数在候选之间比较，核查既能拒答也能纠正选错的对象。

## 三、数据（3,000 题与 6,000 题）
一道题 = 一条描述 + 一组候选框 + 标签（哪个候选是对的，或者都不对；能确定的逐条标签）。全部来自本地已有数据，不需要下载，不需要模型打标签。

| 来源 | 一道题里有什么 | 标签从哪来 | 本地可用 | 6,000 题里用 | 3,000 题里用 |
|---|---|---|---|---|---|
| 自家场景（人审）、跨场景、其他改假版本、长描述、GME 风格、空间关系 | 描述 + 标注实例作候选 | 标签表（被描述实例逐条确定；空间类由几何计算） | 1,375 题（正 440 / 负 935） | 1,375 | 688 |
| RefCOCO / + / g 训练集的人写描述（正样本） | 描述 A + A 的框 + 同图同类另一个对象 B 的框 | 人工标注：A 应通过且每条都成立，B 应被否决 | 17,914 条描述 / 1,028 张图（其中 891 张有同类的另一个对象） | 2,560 | 1,280 |
| 同一批人写描述的规则改假（负样本） | 改掉颜色 / 左右 / 上下前后 / 序数的描述 + A 的框 | 被改的那一条确定为假，原词就是观察值 | 10,151 条可改 | 2,065 | 1,032 |
| 合计 | | | | 6,000（正 3,000 / 负 3,000） | 3,000（正 1,500 / 负 1,500） |

- 3,000 题是 6,000 题的子集，各来源等比例减半，两个点的配比相同，差别只有数据量。
- 6,000 题已经用完本地全部的自家难样本；再往上加只能加人写的描述。难样本扩量（约 600 景，约 30 美元）和 RefCOCO 系列训练图下载（约 1.57 万张）都暂不做，等两个点的结果。
- 验证场景（18 个）和所有评测图片不进训练；GME 的图片与文字永不进入任何训练阶段。

## 四、训练
1. SFT——教格式（现成的 sft_coa，552 题）。
2. 监督打分阶段（新，主体）：
   - 模型在训练题上自己写出条件和每个候选的核查；标签直接作用在每一行判定处的概率上。
   - 三层标签，有哪层用哪层：逐条（这一条该判符合还是不符）、候选（这个候选该通过还是被否决）、整题（哪个候选是对的，或者都不对）。
   - 1 轮；LoRA 秩 16；学习率沿用 SFT 的设置。
   - 第一轮从现有最好的 RL 模型出发（最快看到这一阶段的效果）；冻结配方时按 SFT → 监督打分 → RL 的顺序整条重跑。
3. RL（GRPO）——只管监督管不到的部分：备选提得全不全、条件拆得对不对、最终结果。配方沿用 RL13（每题 8 个 rollout，约 40 步）。
4. 时间（实测推算）：3,000 题 = 写核查文字约 2.5 小时 + 训练约 1.3 小时；6,000 题 = 约 5 小时 + 约 2.5 小时。

| 对照 | 回答什么 |
|---|---|

## 六、评测
| 基准 | 题数 | 测什么 | 用法 |
|---|---|---|---|

| RefCOCO / + / g val | 300 × 3 | 人写短描述的正样本 | 每轮都看（训练集已用，属域内） |
| PR-Bench 开发部分 | 300 拒答 + 50 × 5 类正样本 | 域外拒答 + 分类型正样本 | 每轮都看（已声明为开发集） |
| 自家留出 + 灰图 | 48 + 48 | 域内检查、文字捷径检查 | 每轮都看 |
| PR-Bench 留出部分 | 700 拒答 + 1,000 正样本 | 域外 | 配方冻结后只跑一次 |
| OpenRef | 488 无目标 + 503 单目标 | 域外 | 同上 |
| HumanRef | 1,000 拒答 + 1,000 单人 | 域外 | 同上 |
| FineCops-Ref | 700 负描述 + 300 负图像 + 1,000 正样本 | 域外 | 同上 |
| gRefCOCO | 1,000 无目标 + 1,000 单目标 | 域外（训练集未用） | 同上 |
| Ref-Adv-s | 1,142 | 强干扰正样本 | 同上 |
| MMStar | 1,500 | 通用能力有没有受损 | 每个候选配方跑一次 |

- 指标：拒答准确率；正样本 Acc@0.5（PR-Bench 另报 0.5–0.9 平均）；正样本被答成"没有"的比例；整条"正样本 vs 拒答"曲线，并在两个固定点报数（正样本比基座低不超过 1 分、不超过 3 分时的拒答）。
- 统计：同一批题上的 McNemar 检验（对基座、对各对照）；最终配方 2–3 个种子。
- 诊断：第一个答案正确率、候选里有正确对象的比例、答对被否决、答错被放行、每行误判；每题调用次数和用时。

## 七、实验顺序与判据
| 顺序 | 实验 | 成本 | 判据 |
|---|---|---|---|
| 0 | RL13 评测时记录判定概率，离线比较"按分数择优 + 门槛"与现行规则 | 随 RL13 评测 | 现有模型的分数有没有分辨力（只定基线，不卡后续） |
| 1 | 监督打分，3,000 题 | 约 4 小时 + 评测 | RefCOCO+ / g 答对被否决 ≤ 6%；RefCOCO 最终 ≥ 基座 −3；GME 正样本 ≥ 基座；GME 拒答 ≥ 40；PR 拒答 ≥ 61、PR 正样本 ≥ 基座 −3 |
| 2 | 整体选择对照，同一批 3,000 题 | 约 1 小时 + 评测 | 逐条打分在"正样本持平时的 GME 拒答"上高出 ≥ 3 分才保留逐条机制，否则改用更简单的整体选择 |
| 3 | 监督打分，6,000 题 | 约 7.5 小时 + 评测 | 比 3,000 题在主要指标上再涨 ≥ 2 分 → 值得继续加量（届时再申请下载）；否则数据量到此为止，转向更难的负样本 |
| 4 | 在较好的那个点上接 RL | 约 9 小时 + 评测 | 拒答或正样本再涨，另一项不掉 |
| 5 | 其余对照、种子、冻结配方后的域外评测与 MMStar | 约 3–4 天 | 见第五、六节 |

## 八、创新点定位与风险
- 形式不新：两阶段定位、"候选 + 都不选"（CRS）、逐候选核查后拒答（Rex-Thinker）、同基座的拒答 RL（RC-GRPO）都有先例。
- 可主张的核心：对核查过程本身做逐条、可验证的监督（标签来自正样本标注、规则改假、几何计算，不靠模型判官），以及由此得到的发现——核查的两种只看结果发现不了的失误（照抄描述、按字面较真）和误否决随条件数累积。
- 成立的两个前提：正样本问题解决（第七节实验 1）；逐条监督明显强于整体选择（实验 2）。第二条不成立时，论文的主张改为"数据 + 择优或拒答"，定位相应下调。
- 主要风险：监督训练学到表面规律（第 4–7 轮出现过；这次靠真假严格配对来防）；规则改假只覆盖颜色、方位、序数；候选里没有正确对象时择优无能为力（PR 位置类 70 < 基座 74）。
