# 怎么让模型在特别难的指代样本上真正涨能力（2026-09-16/17）

方法：4 个调研 agent 各读一个方法切片（RL 算法 / grounding 专用方法 / 数据方法 / 验证与测试时计算，共约 200 篇 2025–2026 论文，一手来源），1 个 Innovator 出方案，1 个 Skeptic 对抗审查。中间文件在 `team/methods/`（`m1`–`m4` 调研、`innovator.md`、`skeptic.md`）。标 **P** 的是本项目实测。本文用人话写，每个术语第一次出现时给一句解释。

---

## 0. 一句话结论

**在模型"怎么采样都采不到正确答案"的样本上，普通 RL 学不到任何东西；文献里只有三条路真正在这种样本上涨过能力。我们应该先跑的是其中最便宜、也是唯一有域外迁移记录的那条：成对对比训练（不需要模型自己采出正确答案）。然后用它做冷启动，再接现有的 RL 设计。**

## 1. 问题（你已经定了，这里只是对齐术语）

- 样本：长描述（中位 54 词，5–7 个细节），图里有好几个同类物体。正样本 = 恰好一个物体满足所有细节；负样本 = 每个物体都有一个细节不符，答案是"没有"。
- 现状：Qwen3-VL-8B 正样本 41% 对，338/804 道题把框放在**同类的错物体**上且置信度 >0.999；负样本 0/201，全部框了一个东西。**[P]**
- 关键约束：在这些题上，模型采 16 次也几乎不会采到正确答案（201 道负样本上 p(null) 总和 3.4e-4）。**[P]** 术语：*pass@k* = 采 k 次至少对一次的概率；下面说的"pass@k≈0 样本"就是这种题。
- 这两种失败是同一个操作：模型在读完图和句子的第一遍（prefill）就锁定了一个物体，细节根本没参与选择。"没有"只是"选中零个"这一特例。

## 2. 文献能做什么、不能做什么（每条一个数）

**做不到的（别在这些上花钱）：**

1. **多采样再挑选没用。** GroundingME 自己用最强的 235B thinking 模型采 16 条再挑：Spatial +5.2，**Discriminative +0.1**（66.6→66.7）。16 条里根本没有更好的物体选择可挑。
2. **普通 GRPO 及其所有奖励整形都是 pass@1 锐化。** 8 条 rollout 都框同一个错物体 → 奖励全一样 → 优势为零，DyIoU / 难度加权 / 高斯奖励改的只是奖励值不是组内方差（UniVG-R1 的难度权重是把零乘以一个更大的数）。RC-GRPO 之所以要用 constrained beam search 硬塞 "None"，就是因为组里采不出来。
3. **难度课程、动态采样（DAPO 直接丢掉全错的组）、self-play、on-policy 蒸馏都刻意避开 pass@k≈0 的题。** VisPlay 出题奖励 1−|2c−1| 在 50% 解出率处最大；R-Zero 瞄"能力边缘"；on-policy 蒸馏作者自己说不能增加支撑集。
4. **thinking 模式帮 Spatial、伤 Discriminative，每个尺寸都是**（8B 61.3→52.5，32B 75.0→65.7；Spatial +17 到 +24）。自由 CoT 让模型早早锁定一个物体再围着它推理（"grounding paradox"，2604.11025），轨迹内几乎不纠错。
5. **zoom / 裁剪是花光的杠杆**：小目标上限 +3.34，338 个错框里 183 个在大物体上。**[P]** DeepEyes 81% 的裁剪不含证据。
6. **验证器只在它比策略"知道得更多"时才有用。** 模型自己画框再自问对不对，与正确性相关 r≈0.22；同族验证器准确率 8–23% 时会把自训练变成 −3 到 −11。所有"从 pass@k≈0 到能解"的验证器结果（STV 1.5→21；GUI 反思器 20.3→30.5）都用了带标签或带参考答案的验证器。
7. **把 "none" 塞进坐标流做 SFT 要付正样本**：GroundingME 2:1 混合 Rejection +27.9、Discriminative −21；1:8 就先掉 4 分 Discriminative。**[P + 2512.17495]** 而把"存在与否"做成独立决策（SAM 3 presence head：0→30 个硬负样本/图，定位质量 62.4→62.8 不动）或成对损失，代价为零。

**做得到的（三条路，都有对照证据）：**

| 路 | 机制（人话） | 证据 | 在 grounding 上做过吗 |
|---|---|---|---|
| **A. 部分答案前缀 + 逐题撤掉** | 训练时把正确解的前一部分放在模型前面让它接着写，按原题打分；某题一旦学会就把前缀缩短，最后撤光，部署时不带前缀 | 六篇 2025–26 数学论文，都在"基座 pass@k=0 的子集"上测了不带提示的结果并有 GRPO 对照：QuestA、AdaPrefix-GRPO（17% 的死题被解出）、POPE（pass@128=0）、PrefixRL（pass@512=0 的题 pass@64 +28）、MFC（前缀比例 0/0.25/1 → pass@8 2.2/34/85）、2606.22317（538 道基座解不出的题里 226 道变可解）。反例同样清楚：直接 SFT 完整解会崩（13.6→2.0），一直给提示掉 10 分，简单题混进难题批次会让难题停滞 | **没有。** 没做过 grounding，没做过框，没做过"没有"这个答案 |
| **B. 改变决策单元：从"一次选一个物体"变成"逐候选逐细节核对"** | 让模型先列出同类候选，每个候选逐条打勾/打叉，再给答案 | Rex-Thinker 拆开看：候选列表放进 prompt 让模型"必选"（正样本 +11.8，拒绝 −18）；**逐候选核对才带来拒绝 +13.8，正样本 +0.9**；GRPO 只再加 1 分。而且它的 CoT 教师是看着答案写的（不看答案时教师只有 53.2），所以学生学到的是一种"让自己的判断能组合起来"的格式。冻结权重只换协议也有效：T/F 逐框验证 +9.2，SoM+CoT 在 Ref-Adv +11.4。奖励中间步骤也有效：TreeVGR 奖励轨迹里的框 +12.4，但去掉精度项模型会只枚举不作答（准确率 0） | 只在 L2 负样本（LLM 改写的短句）上做过，候选全来自外部检测器 |
| **C. 成对对比目标** | 不要求模型采出正确答案，只要求它给"正确答案"和"错误答案"打分并拉开差距（DPO 一族）——梯度不依赖 pass@k | 是唯一有稳定域外迁移记录的数据路线（SugarCrepe +5–7，Winoground +6，DASH +2–6），且能把低于随机的项拉起来（VisMin：Idefics2 空间题 18.6→83.0）；S-VCO 的对称损失比 DPO 再 +5 | **没有人在框输出上做过** |

另外一条工具级的线：**Re-Prefill**（2605.12549）——选择在 prefill 就定了，解码不会改；用注意力引导第二次 prefill 在 ScreenSpot-Pro 上 +4.3。没在自然图像上跑过；Skeptic 指出没有证据说明模型在 p>0.999 的错题上注意力还有第二个峰可以提。

**没人报过的数**：任何一篇 REC 论文都没报过基座在其困难子集上的 pass@k；任何一篇 VLM RL 论文都没报过"N 道基座解不出的题训完后解出 M 道"。我们随便一次跑都能补上这张表。

## 3. 方案

Innovator 出了 5 个，Skeptic 审后合并成**两个实验**：一个成对对比目标（原 P2），一个引导式 GRPO 家族（原 P1/P4/P5 是同一实验的不同 rollout 来源，P3 是它的另一种奖励）。下面按 Skeptic 修正后的版本写。

### 3.1 方案一（最先跑）：同图三元组成对训练——教模型"细节变了答案就得变"

**解决什么。** 模型在错的同类物体上很自信，而正确答案从来采不出来，所以 RL 没法惩罚它。成对损失只要求模型**给两个答案打分**，它总能打分，所以在恰恰这些题上有梯度。一个机制同时管正样本（338）和负样本（201）。

**怎么做。**
- 数据：每个源场景（≥3 个同类实例）取目标 T 和"模型实际框错的那个兄弟" S（来自数据引擎门 3 的记录）。写手写 e_T（n 个细节）、e_S（同模板、细节换成 S 的）、e_T⁻（翻转一个细节，没有实例满足），跨族模型验证唯一性和零满足。**再加"翻转措辞但在另一张图上为真"的正样本**（SugarCrepe 修复：防止模型学到"句子怪 → 没有"）。
- 答案串要**在策略上**（模型自己会写出来的坐标串）：错框 b_S 直接用门 3 记录里模型对 e_T 输出的那个框；正确框 b_T 用一句短的、唯一的描述在普通 prompt 下让模型自己框出来。不要用"画红框让它描述"的方式（IVT 证明 4B 不读画上去的框）。
- 损失四个格子 + 一个锚：
  1. 在 e_T 下，b_T 要比 b_S 更可能（正样本失败的直接矫正）
  2. 在 e_S 下，b_S 要比 b_T 更可能（对称：答案跟着细节走）
  3. 在 e_T⁻ 下，"没有"要比 b_T 更可能（负样本）
  4. "没有"在 e_T⁻ 下要比在 e_T 下更可能（"没有"必须是条件性的，不能变成先验）
  5. 锚（mDPO）：b_T 在 e_T 下的概率不能低于训前
- Skeptic 修正的两点：(a) DPO 在初始时每个格子梯度权重相同（对参考模型的对数比为 0），"难度权重自动出现"只在无参考的 ORPO 臂成立，而那正是坐标漂移风险最大的臂——两臂都跑，说清楚；(b) 对坐标 token 做 DPO 比的是**第一个分歧的数字**，不一定是"哪个物体"，所以要加两个变体：只对比第一个分歧 token；以及在方案二的核对块上对比"answer: 2" vs "answer: 3" 这种**答案索引**（干净的"选哪个物体"对比）。
- 训练：4B LoRA，3k 三元组，2 轮，lr 5e-7，20% 格式多样回放；用 `{"boxes": ...}` 格式训、用 GroundingME 原生格式测（协议交换自带）。不需要 rollout，不需要 vLLM。

**为什么能在采不出的样本上起作用。** 路 C 的性质；S-VCO / FINER-tuning 的域外迁移记录；"没有"只是四格之一且条件于孪生句，永远不是固定奖励，所以不会走 2:1 SFT 的老路。

**最接近的三篇 + 差别。** S-VCO（2502.13928，图像对上的对称损失，自由文本答案）→ 我们是框和"没有"、同图文本对、兄弟重定向格。FINER-tuning（2603.17662，从句级负样本 DPO，yes/no 答案）→ 我们是坐标输出、两个竞争的同类物体、负样本来自策略自己的错框。mDPO / OViP → 我们的 rejected 是模型自己在真图上的错框，锚保护的是正确框的概率。

**Kill 实验。** 前置（0.3 GPU-h）：在 200 个三元组上算基座的三个边距（b_T vs b_S 在 e_T 下等）。预期中位数接近 0 或反向；若 >80% 已经正向超过 2 nats，三元组太简单，重跑门 3。主实验（3 GPU-h 训 + 6 评）预注册：留出困难正样本上**错物体率 41% → ≤33%**，误"没有"按尺寸分层 ≤3%；GME dev 拒绝 ≥10 且 Discriminative 掉 ≤2；**Acc@0.9 的涨幅 ≥ Acc@0.5 的涨幅**（坐标漂移是它的专属风险）；灰图上四个边距 ≈0。正样本侧单独失败也是一个值得写的结果（"对坐标做似然训练不能重选物体"）。

### 3.2 方案二（第二跑的是它的 3 GPU-h kill，不是训练）：引导式 GRPO——先替模型写一半核对表，再逐题撤掉

**解决什么。** 模型在核对细节之前就选好了物体。让它先写一张固定格式的短表（每个同类候选一行，每个细节一个 ✓/✗），最后才写答案；训练时我们替它写表的前几行，学会一题撤一题，部署时它自己写。"没有"时不输出任何坐标，坐标流从不见负样本。

**怎么做。**
- 格式：≤60 token 的符号表 + `answer: 2` 或 `answer: none`。细节由纯文本 LLM 逐字拆分。
- 前缀来源（三臂）：A. 构造真值 + Gemma4 跨族判定（候选 = SAM 3 实例）；B. 模型自己看着答案写的解释（ExPO 思路，原 P5）；C. 失败的第一次尝试 + 候选列表作为"重想"提示（Group Revision 思路）。
- 撤前缀（承重部分）：每题前缀比例 ρ 从"8 次里至少对 1 次"的最小值起，该题成功后才降一档，训练 70% 处归零；每组 8 条 = 4 带前缀 + 4 不带（POPE 1:1）；批次里**不混简单题**；前缀 token 不算梯度。
- 奖励：RL-DESIGN §3.1 的集合 F1 + 过度拒绝惩罚，加 0.3 × 表格奖励（候选覆盖率 × 精度 × 判定正确；精度项必须有——TreeVGR 去掉它模型就只枚举不作答）。**不再用强制 None rollout**，前缀取代它。
- 记录：hint reliance（带前缀能对的题里，撤掉前缀后还能对的比例）、不带前缀的成功占比、过度拒绝金丝雀。

**Skeptic 的核心修正：kill 实验原设计测不出能力。** 前缀比例 ρ=1 时表格已经写明每个候选都不满足，模型只需要会读表就能接 "none"——那是格式遵从，灰图对照在 ρ=1 处没有信息。真正有信息的是 ρ∈{0.25, 0.5} 且**决定性的那一行不在前缀里**的题：负样本要模型自己从图里给剩下的行打 ✗。要加的行：按"决定行是否在前缀内"分层；灰图对照放在 ρ=0.5 模型自己写的行上（判定必须接近随机）；训练前先测 ρ=0 时策略自己枚举候选的召回率（低于 60% 就是"伪装的检测器"）；ρ=0 的格式代价要在 **4B** 上测且同时报 Acc@0.5 / Acc@0.9 / Rejection / 误 null（thinking 的 Discriminative 下降可能是"多了一个 none 选项"带来的先验位移，一个活的 none 选项会复现它）。**曲线是台阶（ρ<1 平、ρ=1 跳）就说明这一家在 grounding 上行不通，不用等训练。**

**为什么这一家在 grounding 上可能整体失败（要正视）。** 数学里前缀和答案是同一种 token，写了一半的证明约束剩下的证明；grounding 里答案是一个在 prefill 就定死的坐标，表格是模型从没见过的跨族文本格式，而且 ✓/✗ 可以从句子措辞里填出来（GME 负样本文本可分性 0.92）。写了一半的表是"半份文档"，不是"半次视觉计算"。信号：台阶曲线、ρ=0.5 处灰图判定高于随机、训完 hint reliance >0.7。

**Kill（约 3 GPU-h，本地）：** 100 dev 负样本 + 100 错物体正样本 + 100 正确正样本，ρ∈{0,.25,.5,.75,1} × 8 采样，加上述分层与对照；同一趟顺带做方案三的解释提升测试和"thinking + SoM 候选列表在 GME Discriminative 上"这个最便宜的探针。

### 3.3 方案三（作为仪器先跑，作为奖励后跑）：问而不告的验证器

**解决什么。** 验证器要比策略强，只有两条路：看得更少（一个候选 + 一个细节）、或用策略没见过的标签训练。把每个细节改成"值被扣掉"的问题（"蓝衬衫" → "画框里的人衬衫什么颜色？"，正确值 "蓝"），对一个候选提问，把回答和扣掉的值比对。没有 yes-bias，不能从句子里抄答案，而且输出是"n 个细节里满足 k 个"的分级信号。

**三个阶段。** 0：零样本仪器，按子轴报 AUROC。1：用编辑流水线的来源标签（哪个细节被改假）训练一个跨族 critic（Gemma4 或 Molmo2 LoRA），C 对照按"满足"喂入防止学到"被编辑 = 不符"。2：作为选择器（只算协议，不算能力）。3：替换方案二里的构造真值判定，让 RL 能在**没有标签的**拥挤图片上训。

**Skeptic 的两处修正。** (a) 候选判定 = 所有细节取 min，每细节 10% 误判在 6 个细节上复合成 47% 误"没有"，原 5% 护栏算术上不可达——要么每细节 ≤0.9%，要么换成校准的 k-of-n 规则。(b) 扣掉值只是把捷径挪进**答案先验**（"衬衫什么颜色"的常见答案）——必须加一个纯文本回答者作为地板，真图 AUROC 要高于它。

**Kill（Text 子轴 0.25 GPU-h 先跑，全部 1.5–3 GPU-h）：** Text ≥0.85、Appearance/State ≥0.70；比 yes/no 形式高 ≥0.05；跨族零样本行不低于 Qwen 行；灰图 AUROC ≈0.5；纯文本回答者地板。Stage 1 训后 held-out ≥0.85 且 C 对照 ≈0.5。

### 3.4 组合主方法（Skeptic 认为最强）：方案一做冷启动 → 现有 RL 设计（S3）做第二阶段

- 用成对损失先在 338 和 201 上"制造支撑"（不需要采样），其中"选哪个物体"的对比用方案二的核对表上的答案索引形式；
- 然后在同一批题上跑 RL-DESIGN S3 的 GRPO，此时组内有了方差；
- 核对表通过协议交换撤掉（训时有、测时用普通 prompt）。
- 这正是 Rex-Thinker 被证明有效的顺序（域内冷启动 → RL 再加 1 分），只是把"看着答案写的教师轨迹"换成一个不需要教师的损失。它同时消掉方案二最大的风险（学到格式没学到核对）和它的调度机器。

### 3.5 对照臂（缺了它们主结果不可解释）

| 臂 | 为什么必须 |
|---|---|
| **RL-DESIGN S3 原样**（强制 None、α=0.5） | 它就是 survey 里缺失的"RC-GRPO 在 GroundingME 上"的数字；永远不单独跑，作为对照列和方案一的第二阶段 |
| **SFT-on-the-block**（1:8、低 lr、回放） | Rex-Thinker 的 +13.8 来自 SFT；"SFT 会崩"的证据是数学的，GroundingME 的崩是配比效应（1:8 保住了正样本）。没有它分不清"前缀 RL"和"任何接触过核对表" |
| **全参 lr 1e-6 臂** | CAPABILITY §4 里最便宜的抗遗忘手段；所有主实验都是 LoRA。来源 id 仍未核（跑前先找到） |

## 4. 没人做过、我们能做的（创新点清单）

1. 在 grounding 上做带撤回的前缀/提示 RL，并在不带提示的普通 prompt 下测"基座解不出的题解出了多少"——这张表任何 VLM RL 论文都没有。
2. 在框输出上做成对目标；"兄弟重定向"格子；用策略自己的错框做 rejected。
3. 为一句指代表达式画"解锁曲线"（MFC Table 1 的 REC 版）。
4. 跨族逐细节判定作为前缀来源；结构化表格前缀是否跨族迁移。
5. 值被扣掉的问题作为验证单元；来源标签训练的跨族 critic；(裁剪 + 一个细节) vs (全图 + 整句) 按细节类型分层的比较。
6. 在自然图像 REC 上做 Re-Prefill；细节注意力的"软与"作为重选；注意力图与中心名词图的相关系数本身就是可发表的诊断（若 >0.9，说明细节根本没有注意力质量——D2 的机制解释）。
7. Skeptic 补的：**用修复（inpainting）做测试时仪器和定向 "none" rollout 来源**——把模型选的物体抹掉再问，若它以 >0.999 又框下一个兄弟，说明第一次不是看证据；抹到场景为空的那条链是一条**可采样的 "none" 轨迹**，是有方向的离策略引导（S3 的强制常量没有方向）。约 1 GPU-h，用现有引擎，没人做过。
8. 从句级循环一致性奖励：让模型不看句子描述框中物体，再逐从句比对——不需要构造真值的分级负样本奖励。
9. 1:8 配比 SFT 的 GME Rejection 值（论文没印，1 GPU-h）。
