## 2. 轨迹（单轮）

```
<conditions>1. 黑头  2. 白胸  3. 站在石头上  4. 在另外两只鸟前面</conditions>
<candidates>
<object id="1" bbox="[261,491,550,813]">1: yes  2: yes  3: yes  4: yes → 满足</object>
<object id="2" bbox="[…]">1: no  2: yes  3: no  4: no → 排除</object>
</candidates>
<answer>{"bbox_2d": [261,491,550,813]}</answer>
```

记条件数 J，候选 k 的框 b_k，判决 v_{k,j} ∈ {yes, no, unclear}。推导答案 derive(T)：没有任何明确 no 的候选恰一个 → 其框；多个 → yes 最多者；每个候选都至少一个 no → null。unclear 不算 no。候选数上限 6。V5 把每格改为 `2: 说 白胸 / 看到 棕胸 → no`，且没有"看到"值的 no 按 unclear 计。

## 3. SFT loss

对每条渲染轨迹 y（`<conditions>` 到 `</answer>` 的全部 token），prompt x 为图像加描述：

L_SFT = −(1/|y|) Σ_t log π_θ(y_t | x, y_<t)

prompt 部分遮掉，不加权、不加 unlikelihood、不单独加权决策 token。LoRA r16 挂在语言模型的注意力与 MLP 上，视觉塔冻结。lr 1e-4，1 轮，约 450 条。验收：验证场景格式合法率 ≥ 95%；负样本 null 上升且正样本误拒不升。

## 4. GRPO

每题采样 G = 8 条完整轨迹 o_i，奖励 r_i，组内归一化优势 A_i = (r_i − mean r) / (std r + ε)。目标函数是标准 GRPO：

L = −(1/G) Σ_i (1/|o_i|) Σ_t min(ρ_{i,t} A_i, clip(ρ_{i,t}, 1−ε, 1+ε) A_i) + β·KL(π_θ ‖ π_ref)

每组采样只做一次梯度更新（ρ = 1），快速迭代阶段 β = 0。从 V1 检查点续训同一个 LoRA。只用 SFT 后解出率在 (0, 1) 的题；负样本一组里没有 null 时注入渲染的标签轨迹作为一条完整完成（昨夜验证过的解锁方式）。同图的正负孪生题放在同一步。

## 5. Reward

解析 o 得到表 T、自写答案 a、推导答案 â = derive(T)。解析失败或候选数不在 1..6 或某候选判决数 ≠ J：r = −1，结束。否则 r = r_ans + 0.1 + r_pen。

**r_ans，V2（独立奖励，领域标准）**
- 正样本（真值框 g）：a 是框且 IoU(a, g) ≥ 0.5 → +1；框但 IoU < 0.5 → 0；a = null → −1。
- 负样本与跨场景负样本：a = null → +1；框 → 0。

**r_ans，V3（对级奖励）**
- 负样本 x⁻ 的同图正样本孪生 x⁺ 在同一步采样，s⁺ = 其 8 条里答对框的比例。x⁻ 的 null 得 s⁺，框得 0。正样本不变。s⁺ = 0 时该负样本组奖励全零、无梯度：定位都做不到的场景不奖励拒答。跨场景负样本无孪生，按 V2。

**r_pen，V4（在 V3 上加三项）**
- 指控门控：负样本被改句序号 j*，若 ∃k: v_{k,j*} = no，null 得满分 s⁺；否则 ×0.2。
- 假指控惩罚：正样本里与 g 匹配（IoU ≥ 0.5）的候选 k*，若 ∃j: v_{k*,j} = no → −0.5。
- 一致性：a 与 â 不一致（null/框不同，或两框 IoU < 0.5）→ −0.5。

**V5**：奖励同 V4，轨迹换观察值格式。

不加候选框 F1、过程奖励、任何无条件加分；出现枚举刷分再加精度项。

## 6. 评测（每变体一次，目标 ≤ 15 分钟）

昨夜的 screening 是 20 分钟：GME 351 条约 9 分钟、灰图 5 分钟、自家 2 分钟、RefCOCO 900 条 5 分钟，逐条生成、输出不到 64 token。换成 200–300 token 的轨迹后逐条生成会到一小时以上，必须简化：

- 集合：GME 开发子集（201 拒答 + 150 分层正样本）、自家验证 48、RefCOCO 每集 100。灰图对照与全集只给最终候选。
- 生成：批量 8 条左填充，max_new 320。预计 GME 约 10 分钟、其余约 3 分钟。
- 训练中途看趋势用 5 分钟的小集：100 拒答 + 60 正样本 + 自家 48。

报的数：净拒答（拒答率 − 正样本误拒率）、正样本误拒计数、RefCOCO 三集、自家配对双正确率、指控准确率、真子句误判为 no 的每条比率、推导与自写答案一致率、格式合法率。主报推导答案。所有比较逐题配对。

## 7. 假设、判据、顺序

| 假设 | 对比 | 通过 |
|---|---|---|
| H1 格式本身离开交换线 | V1 vs 昨夜坐标流 SFT | 净拒答 ≥ +0.10，RefCOCO 掉幅 ≤ 2 |
| H2 对级奖励解耦 | V3 vs V2 | 净拒答再 +0.05，配对双正确率上升 |
| H3 门控与一致性降误拒 | V4 vs V3 | 误拒计数下降，拒答率变化 ≤ 3 点 |
| H4 观察值更准 | V5 vs V4 | 真子句误判率下降，假子句检出不降 |
| H5 现有像素上限看得见 | 零样本分辨率测试 | 假子句检出 ≥ 0.70 且真子句误判 ≤ 0.15，否则再议裁剪回合 |

顺序：第 0 天代码（渲染器、解析与推导、奖励与孪生同步、批量评测）；三个零样本预测试（分辨率；观察值 vs yes/no；推导 vs 自写答案）；一晚 V1 → V2 → V3 → V4 → V5。停止规则：V1–V5 净拒答全 < 0.05 则格式在 4B 上不迁移，回头看数据与裁剪，不再堆奖励项。
